# LightPlayer 1.0 pre-release

[简体中文](v1.0.0.md) | English

LightPlayer is a lightweight media player for macOS with local AI lyrics recognition built in. This is a pre-release of 1.0; please try it and report problems.

## Download and install

- For Macs with **Apple Silicon (M-series chips)**, running **macOS 12** or later.
- Download `LightPlayer_1.0.0_aarch64.dmg` below, open it and drag LightPlayer into Applications.
- This version is not notarized by Apple. If macOS says it is "damaged" or the developer "can't be verified" the first time you open it, right-click LightPlayer in Applications and choose "Open", or run in Terminal:

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

## Main features

- **Plays every format**: with ffmpeg built in, MP3, FLAC, APE, WMA, DSD, MKV, AVI, RMVB and more play directly; when needed, files are remuxed or transcoded live with hardware encoding, and seeking stays smooth.
- **Playback control**: play / pause, previous / next, forward / back 15 seconds, in order / repeat all / repeat one / shuffle; the progress bar can be dragged or moved with the arrow keys; the volume changes only the app, not the system. Also playback speed, A-B loop, sleep timer and resume playback.
- **Playlist**: lists the files of the same kind in the same folder (audio lists only audio, video only video); a single click plays; the list can be folded away.
- **Lyrics**:
  - Loads lyrics with the same name (LRC, SRT, VTT, TXT, with GBK and Big5 detected) or embedded lyrics.
  - Scrolling highlight that stays centered, click to jump, word-by-word karaoke, translation lines, global offset and font size.
  - Upload a lyrics file, or make lyrics by hand: tap along as you listen, fill in times line by line, preview and save next to the song.
- **AI lyrics recognition**:
  - Uses a local Whisper model (Metal-accelerated); the model is downloaded the first time.
  - Recognition is fully offline; no audio is ever uploaded.
  - Results are marked "These lyrics were made by a recognition model and may contain errors" and can be proofread right away.
  - Videos can get subtitles the same way.
- **Video**:
  - A details panel with size, resolution, frame rate, bit rates, codecs and more.
  - External and embedded subtitles.
  - Screenshots and frame stepping.
  - Immersive full screen: the control bar and title bar hide automatically.
- **Library**:
  - Added folders are scanned with all their subfolders, played files are recorded automatically, and files can be dragged in.
  - Browse by songs, albums, artists and videos, with search and sorting.
  - Favorites and your own playlists.
  - Playing from the library makes the current list the play queue.
- **Appearance**:
  - Light and dark themes, a custom accent color (default #66ccff), optionally taken from the cover.
  - Custom background images.
  - A subtle live waveform animation at the bottom of the lyrics page.
- **System integration**: "Open With" in Finder, "Now Playing" in Control Center, keyboard media keys.

## Known limitations

- Not notarized by Apple; the first time you open it, allow it as described above.
- Only an Apple Silicon version for now, no Intel version.
- AI recognition needs a model download the first time (the recommended model is about 550 MB); a mirror for mainland China can be chosen in Settings.
- The bundled ffmpeg is a GPL build, for personal use only.
- Picture subtitles such as PGS and VobSub are not supported yet.
