# LightPlayer 1.0 预发布

LightPlayer 是一款轻量的 macOS 多媒体播放器，内置本地 AI 歌词识别。这是 1.0 的预发布版本，欢迎试用并反馈问题。

## 下载与安装

- 适用于 **Apple Silicon（M 系列芯片）** 的 Mac，需要 **macOS 12** 或更高版本。
- 下载下方的 `LightPlayer_1.0.0_aarch64.dmg`，打开后把 LightPlayer 拖进“应用程序”。
- 本版本未经 Apple 公证。首次打开如果提示“已损坏”或“无法验证开发者”，请在“应用程序”中右键 LightPlayer 选择“打开”，或在终端执行：

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

## 主要功能

- **全格式播放**：内置 ffmpeg，MP3、FLAC、APE、WMA、DSD、MKV、AVI、RMVB 等格式都能直接播放；需要时自动转封装或用硬件实时转码，拖动进度依然流畅。
- **播放控制**：播放 / 暂停、上一曲 / 下一曲、前进 / 后退 15 秒、顺序 / 列表循环 / 单曲循环 / 随机，进度条支持拖动和方向键；音量只调节应用自身，不影响系统音量。还有倍速、A-B 段落循环、睡眠定时、断点续播。
- **播放列表**：自动列出同一文件夹里的同类文件（音频只列音频，视频只列视频），单击即播，可以收起。
- **歌词**：
  - 自动加载同名歌词（LRC、SRT、VTT、TXT，自动识别 GBK、Big5 编码）或内嵌歌词。
  - 滚动高亮并始终居中，点击跳转，支持逐字卡拉 OK、翻译行、整体偏移和字号调节。
  - 可以上传歌词文件，也可以手动制作：边听边打标、逐行填写时间、预览后保存到歌曲旁边。
- **AI 识别歌词**：
  - 使用本地 Whisper 模型（Metal 加速），首次使用时下载模型。
  - 识别完全离线进行，不会上传任何音频。
  - 识别结果会标注“本歌词由识别模型生成，可能有误”，可以直接编辑校对。
  - 视频同样可以生成字幕。
- **视频**：
  - 详细信息面板，显示大小、分辨率、帧率、码率、编码等。
  - 外挂和内嵌字幕。
  - 截图和逐帧步进。
  - 沉浸式全屏：控制栏和顶栏会自动隐藏。
- **媒体库**：
  - 添加文件夹后会扫描所有子文件夹，播放过的文件自动记录，也可以把文件拖进来。
  - 按歌曲、专辑、艺术家、视频浏览，支持搜索和排序。
  - 可以收藏，也可以自建歌单。
  - 从媒体库点开时，播放队列就是当前列表。
- **外观**：
  - 浅色和深色主题，自定义主题色（默认 #66ccff），可以随封面变色。
  - 支持自定义背景图片。
  - 歌词页底部有低调的实时声波动画。
- **系统集成**：Finder“打开方式”，控制中心“正在播放”，键盘媒体键。

## 已知限制

- 未经 Apple 公证签名，首次打开需要按上面的方法放行。
- 暂时只提供 Apple Silicon 版本，没有 Intel 版本。
- AI 识别第一次使用需要下载模型（推荐模型约 550 MB），可以在设置中切换到国内镜像。
- 内置的 ffmpeg 是 GPL 构建，仅供个人使用。
- 暂不支持 PGS、VobSub 等图形字幕。
