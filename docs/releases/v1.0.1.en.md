# LightPlayer 1.0.1 pre-release

[简体中文](v1.0.1.md) | English

Fixes several problems in 1.0 that got in the way, and adds recognition task management, a menu bar icon and more.

## Download and install

- For Macs with **Apple Silicon (M-series chips)**, running **macOS 12** or later.
- Download `LightPlayer_1.0.1_aarch64.dmg` below, open it and drag LightPlayer into Applications (it can replace the old version; your library and settings are kept).
- This version is not notarized by Apple. If macOS says it is "damaged" or the developer "can't be verified" the first time you open it, right-click LightPlayer in Applications and choose "Open", or run in Terminal:

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

## Fixes

- **Library turning black**: scrolling the song list in the library while music played turned the whole window black and unusable. Fixed; and should the interface ever hit an unexpected error, it now shows a recoverable message instead of a black screen.
- **Seeking lag**: after dragging the progress bar or clicking a lyric to jump, about 0.4 s of audio from the old position played first. Seeking now takes effect immediately.
- **Hard-to-read text over background images**: with a background image in the light theme, or the blurred cover background on the lyrics page, the sidebar, the title bar and the non-current lyric lines were too faint. Text contrast now rises automatically, and the library sidebar got a frosted-glass backing.

## New features

- **Recognition task management**:
  - Lyrics and subtitle recognition is queued and runs one task at a time.
  - A new recognition tasks button in the title bar shows progress; pause or resume the queue, cancel, reorder and retry.
  - Right-click in the library to recognize a single song or a whole list at once.
- **More choices for AI lyrics**: the "Lyrics source" menu at the top right of the lyrics page can:
  - look for a local lyrics file again;
  - upload a lyrics file;
  - recognize again (with another model if you like);
  - remove the AI lyrics and go back to no lyrics.

  The subtitles menu for videos can likewise recognize again or remove the AI subtitles.
- **Background playback and a menu bar icon**:
  - Music keeps playing after the window is closed; the icon in the menu bar plays / pauses, skips, reopens the window or quits.
  - It can be turned off under "Settings > Playback > Background & menu bar", where you can also show the song title in the menu bar.
- **Opens to the library**: the app now opens to the library; the player page has a new "Back" button at the top left. Opening a file from Finder still goes straight to the player page.

## Other changes

- Removed the waveform animation at the bottom of the lyrics page.

## Known limitations

- Not notarized by Apple; the first time you open it, allow it as described above.
- Only an Apple Silicon version for now, no Intel version.
- AI recognition needs a model download the first time (the recommended model is about 550 MB); a mirror for mainland China can be chosen in Settings.
- The bundled ffmpeg is a GPL build, for personal use only.
- Picture subtitles such as PGS and VobSub are not supported yet.
