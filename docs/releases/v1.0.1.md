# LightPlayer 1.0.1 预发布

在 1.0 的基础上修复了几个影响使用的问题，并加入识别任务管理、菜单栏图标等功能。

## 下载与安装

- 适用于 **Apple Silicon（M 系列芯片）** 的 Mac，需要 **macOS 12** 或更高版本。
- 下载下方的 `LightPlayer_1.0.1_aarch64.dmg`，打开后把 LightPlayer 拖进“应用程序”（可直接覆盖旧版本，媒体库和设置会保留）。
- 本版本未经 Apple 公证。首次打开如果提示“已损坏”或“无法验证开发者”，请在“应用程序”中右键 LightPlayer 选择“打开”，或在终端执行：

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

## 修复

- **媒体库变黑**：播放音乐时在媒体库里滚动歌曲列表，整个窗口会变黑且无法操作。现已修复；即使界面以后出现意外错误，也会显示可恢复的提示，而不是一片黑。
- **拖动进度有延迟**：拖动进度条或点击歌词跳转后，会先继续播放约 0.4 秒原来位置的声音。现在跳转立即生效。
- **背景图上文字看不清**：浅色主题设置背景图，或歌词页使用模糊封面背景时，侧栏、标题栏和非当前歌词行颜色过浅。现在文字对比度会自动提高，媒体库侧栏也加上了毛玻璃底板。

## 新功能

- **识别任务管理**：
  - 歌词和字幕识别会排队依次进行。
  - 标题栏新增识别任务按钮，可查看进度，暂停或继续队列，取消、调整顺序和重试。
  - 媒体库右键可以识别单首歌曲，也可以一次识别整个列表。
- **AI 歌词的更多选择**：歌词页右上角的“歌词来源”菜单可以：
  - 重新查找本地歌词文件；
  - 上传歌词文件；
  - 重新识别（可换其他模型）；
  - 移除 AI 歌词，回到无歌词状态。

  视频的字幕菜单同样可以重新识别或移除 AI 字幕。
- **后台运行与菜单栏图标**：
  - 关闭窗口后音乐继续播放，顶部菜单栏图标可以播放 / 暂停、切歌、重新打开窗口或退出。
  - 可在“设置 > 播放 > 后台与菜单栏”中关闭此功能，也可以选择在菜单栏显示歌名。
- **默认进入媒体库**：打开 App 时直接进入媒体库；播放页左上角新增“返回”按钮。从访达打开文件时仍会直接进入播放页。

## 其他变化

- 移除了歌词页底部的声波动画。

## 已知限制

- 未经 Apple 公证签名，首次打开需要按上面的方法放行。
- 暂时只提供 Apple Silicon 版本，没有 Intel 版本。
- AI 识别第一次使用需要下载模型（推荐模型约 550 MB），可以在设置中切换到国内镜像。
- 内置的 ffmpeg 是 GPL 构建，仅供个人使用。
- 暂不支持 PGS、VobSub 等图形字幕。
