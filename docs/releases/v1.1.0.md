# LightPlayer 1.1.0

简体中文 | [English](v1.1.0.en.md)

新增天气主题、桌面歌词、无痕浏览等功能，改进了播放列表和歌词显示，并修复了多个问题。

## 下载与安装

- 适用于 **Apple Silicon（M 系列芯片）** 的 Mac，需要 **macOS 12** 或更高版本。
- 下载下方的 `LightPlayer_1.1.0_aarch64.dmg`，打开后把 LightPlayer 拖进“应用程序”（可直接覆盖旧版本，媒体库和设置会保留）。
- 本版本未经 Apple 公证。首次打开如果提示“已损坏”或“无法验证开发者”，请在“应用程序”中右键 LightPlayer 选择“打开”，或在终端执行：

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

## 新功能

- **天气主题**：在“设置 > 外观 > 外观模式”中选择“天气”。
  - App 会获取你所在位置的实时天气，整个界面换成对应的动态天空：晴天的阳光、随天气变化的薄纱云带、雨、雷电、雪、冰雹、雾，以及夜晚的月亮和星空；黎明和黄昏的天色也会变化。
  - 雨滴、雪花和冰雹会落在播放栏、封面和弹窗等界面元素上：雨滴溅起水花，雪会积起薄薄一层再慢慢融化，冰雹会弹跳。
  - 标题栏显示当前天气和温度，点击可查看体感温度、湿度、风速和日出日落时间。
  - 第一次使用时 macOS 会询问是否允许 LightPlayer 使用定位；不允许时改用网络大致位置，也可以在设置中指定城市。
  - 天气数据来自 Open-Meteo，地名来自 BigDataCloud，都免费且无需账号。
- **桌面歌词**：点播放栏中的桌面歌词按钮，打开悬浮在所有窗口之上的歌词条。
  - App 最小化或关闭窗口在后台播放时，桌面歌词照常滚动。
  - 每次显示一行，换行时带动画。
  - 鼠标移上去可以改颜色、在右上角关闭；按住拖动位置，拖右下角调整大小（字号随之变化），位置和大小会被记住。
  - 歌词页现在从播放栏左下角的歌曲信息进入（或按 Y）。
- **播放列表**：
  - 拖动左侧的把手调整播放顺序；鼠标移到某一项上点“×”或右键可以把它移出列表（文件不会被删除）。
  - 右键还可以“下一首播放”。
  - 歌词页也能显示播放列表；窗口较窄时，播放列表以悬浮面板显示，不再挤占歌词。
- **歌词高亮颜色**：歌词页右上角的色点（或“设置 > 歌词”）可以改当前歌词行的颜色。
- **媒体库**：
  - 专辑可以从媒体库移除（文件保留，刷新文件夹也不会再加回来），或直接移到废纸篓；在专辑上右键，或在专辑页点“更多”。
  - 在侧栏“歌单”旁可以把一个文件夹导入为歌单：里面的音乐和视频会加入媒体库，并建立一个以文件夹命名的歌单。
- **一键设为默认播放器**：在“设置 > 播放 > 文件关联”中点“一键设置”，常见的音频和视频格式都会默认用 LightPlayer 打开，双击文件即可播放。
- **连续播放与后台播放视频**：在“设置 > 播放”中可以分别设定音乐和视频播完后是否自动播放下一个（默认音乐连播、视频播完即停），以及关闭窗口后视频是否继续在后台播放（默认暂停视频，音乐照常播放）。
- **网易云音乐（试验性）**：在“设置 > 网易云音乐”中开启后，可以在网易云音乐官方网页中登录（密码、短信验证码或二维码），也可以用手机扫码登录，在媒体库侧栏播放你的歌单、我喜欢的音乐和每日推荐，也可以搜索歌曲，歌词使用网易云音乐提供的版本。
  - 这项功能使用网易云音乐网页版的非官方接口，随时可能失效；使用第三方客户端也违反网易云音乐的用户协议，账号存在被限制的风险。
  - 会员歌曲只有会员账号才能完整播放，否则只能试听片段；无法播放或只能试听时，会提示网易云音乐给出的原因。LightPlayer 不会下载或破解任何歌曲。
- **无痕浏览模式**：开启后，打开的文件不会出现在最近播放中，不记录播放次数和播放位置，也不会自动加入媒体库。可在“设置 > 播放 > 隐私”、菜单栏图标的菜单中切换，或按 ⇧⌘N。

## 修复

- **歌词越来越快**：部分从音乐平台下载的文件，会让播放计时越走越偏，歌词开头对得上、越往后越提前。现在 App 会自动检测这类文件，改用精确计时播放；如果仍然对不上，可以在歌词页右上角的“…”菜单中手动开启“精确计时”。
- **跳转后歌词错位**：点击歌词、拖动进度条或前进/后退 15 秒后，MP3 和 FLAC 有时会从偏前或偏后的位置开始播放，歌词因此比歌声快或慢。现在 App 会在开始播放后于后台准备一份可以精确跳转的副本，之后的跳转都从准确的位置继续。
- **双击文件只打开主界面**：App 没有运行时双击媒体文件，App 启动后不会播放这个文件。现在会直接开始播放。
- **播放页歌词预览**：切换歌词时封面和歌曲信息会轻微移动，现已固定；歌词切换时带淡入淡出动画。
- **视频回不到播放页**：播放视频时退回媒体库后，点播放栏左侧的视频信息没有反应。现在点击它就会回到视频播放页，媒体库侧栏顶部也会显示“正在播放视频”。

## 其他变化

- 歌词页顶部只显示歌名和歌手，不再显示封面。
- 歌词中的空白行（间奏）不再显示音符占位，上一句歌词会一直显示到下一句开始。
- 媒体库“艺术家”页的头像缩小一半。
- 全屏播放视频时，右上角不再显示退出全屏按钮，使用播放栏中的按钮或按 Esc 退出。

## 已知限制

- 未经 Apple 公证签名，首次打开需要按上面的方法放行。
- 暂时只提供 Apple Silicon 版本，没有 Intel 版本。
- 从访达双击打开文件时，macOS 自己可能会把它加入“最近使用的项目”，这不受无痕浏览模式控制。
- AI 识别第一次使用需要下载模型（推荐模型约 550 MB），可以在设置中切换到国内镜像。
- 内置的 ffmpeg 是 GPL 构建，仅供个人使用。
- 暂不支持 PGS、VobSub 等图形字幕。
