# LightPlayer 1.1.0 预发布

新增天气主题和无痕浏览模式，并修复了视频播放时从媒体库回不到播放页的问题。

## 下载与安装

- 适用于 **Apple Silicon（M 系列芯片）** 的 Mac，需要 **macOS 12** 或更高版本。
- 下载下方的 `LightPlayer_1.1.0_aarch64.dmg`，打开后把 LightPlayer 拖进“应用程序”（可直接覆盖旧版本，媒体库和设置会保留）。
- 本版本未经 Apple 公证。首次打开如果提示“已损坏”或“无法验证开发者”，请在“应用程序”中右键 LightPlayer 选择“打开”，或在终端执行：

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

## 新功能

- **天气主题**：在“设置 > 外观 > 外观模式”中选择“天气”。
  - App 会获取你所在位置的实时天气，整个界面换成对应的动态天空：晴天的阳光、云、雨、雷电、雪、冰雹、雾，以及夜晚的月亮和星空；黎明和黄昏的天色也会变化。
  - 雨滴、雪花和冰雹会落在播放栏、封面和弹窗等界面元素上：雨滴溅起水花，雪会积起薄薄一层再慢慢融化，冰雹会弹跳。
  - 标题栏会显示当前天气和温度，点击可查看体感温度、湿度、风速和日出日落时间。
  - 第一次使用时 macOS 会询问是否允许 LightPlayer 使用定位；不允许时改用网络大致位置，也可以在设置中指定城市。
  - 设置中可以关闭动态效果，也可以用“效果预览”查看各种天气的效果。
  - 天气数据来自 Open-Meteo，地名来自 BigDataCloud，都免费且无需账号。
- **无痕浏览模式**：开启后，用 LightPlayer 打开的文件不会留下记录：不出现在最近播放中，不记录播放次数和播放位置，也不会自动加入媒体库。
  - 可在“设置 > 播放 > 隐私”、菜单栏图标的菜单中切换，或按 ⇧⌘N。
  - 开启时标题栏会显示“无痕”标记，点击即可关闭。

## 修复

- **视频回不到播放页**：播放视频时退回媒体库后，点播放栏左侧的视频信息没有反应，只能听到声音。现在点击它就会回到视频播放页，媒体库侧栏顶部也会显示“正在播放视频”，点击即可返回。在媒体库里再点一次正在播放的视频，也不会再从头开始。

## 其他变化

- 媒体库“艺术家”页的头像缩小一半。
- 全屏播放视频时，右上角不再显示退出全屏按钮，使用播放栏中的按钮或按 Esc 退出。

## 已知限制

- 未经 Apple 公证签名，首次打开需要按上面的方法放行。
- 暂时只提供 Apple Silicon 版本，没有 Intel 版本。
- 从访达双击打开文件时，macOS 自己可能会把它加入“最近使用的项目”，这不受无痕浏览模式控制。
- AI 识别第一次使用需要下载模型（推荐模型约 550 MB），可以在设置中切换到国内镜像。
- 内置的 ffmpeg 是 GPL 构建，仅供个人使用。
- 暂不支持 PGS、VobSub 等图形字幕。
