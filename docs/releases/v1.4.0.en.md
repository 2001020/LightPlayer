# LightPlayer 1.4.0

[简体中文](v1.4.0.md) | English

Adds the Flow player style: a cover wall modeled on the classic Cover Flow, for flipping through the playlist.

**The first Windows version**: LightPlayer now comes for both macOS and Windows, with nearly the same features.

## Download and install

### macOS

- For Macs with **Apple Silicon (M-series chips)**, running **macOS 12** or later.
- Download `LightPlayer_1.4.0_aarch64.dmg` below, open it and drag LightPlayer into Applications (it can replace the old version; your library and settings are kept).
- This version is not notarized by Apple. If macOS says it is "damaged" or the developer "can't be verified" the first time you open it, right-click LightPlayer in Applications and choose "Open", or run in Terminal:

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- For **Windows 10 / 11 (64-bit)**.
- **Installer (recommended)**: download `LightPlayer_1.4.0_x64-setup.exe` and run it. It installs for the current user without administrator rights, adds LightPlayer to the Start menu, and can be uninstalled under "Settings > Apps".
- **Portable**: download `LightPlayer_1.4.0_x64_portable.zip`, unzip it and run `LightPlayer.exe` in the folder (keep `ffmpeg.exe` and `ffprobe.exe` next to it).
- The installer is not code-signed. If you see "Windows protected your PC", click "More info", then "Run anyway".
- The Microsoft Edge WebView2 runtime is needed: Windows 11 and recent Windows 10 include it; otherwise the installer downloads and installs it, and for the portable version please install it from Microsoft's website first.

## New features

- **Windows version**
  - The window looks like the macOS version, with minimize, maximize and close buttons at the top right. Drag the title bar to move the window; double-click it to maximize.
  - ⌘ in shortcuts is Ctrl on Windows, e.g. Ctrl+O to open a file, Ctrl+L for the library, Ctrl+Shift+N for private browsing. Button hints and "Settings > Shortcuts" show Ctrl too.
  - Keeps playing in the background after the window is closed: click the LightPlayer icon in the notification area at the right of the taskbar to open the window; right-click it to play / pause, skip or quit.
  - Supports the keyboard's media keys and the system media overlay that appears when changing the volume (showing the song title and cover, with play / pause and skip).
  - LightPlayer can be chosen from "Open with" when right-clicking a file. If LightPlayer is already running, double-clicking a file opens it in the existing window instead of a new one.
  - "Show in File Explorer" and "Move to Recycle Bin" work in the library and the playlist.
- **Flow player style**: while music plays, click the "Flow" button at the top right of the player page, or choose "Flow" under "Settings > Appearance > Player style".
  - The songs in the playlist are laid out as a 3D cover wall: the playing song faces you, the covers on either side are tilted and stacked, with mirror reflections below; when the song changes the covers slide to the middle.
  - Flip through the list with the mouse wheel, by dragging the covers left and right, or with the scroll bar below.
  - Click a cover on either side to turn it to the middle, then click again (or just double-click any cover) to play that song.
  - With the playing song in the middle, the current and next lyric lines show below; click the cover or the title to open the lyrics page.
  - After you browse other songs and stop for a few seconds, it returns to the playing song by itself.
  - Follows the light, dark, weather or background image theme; local songs show their embedded or folder covers, NetEase songs their album covers.
  - To go back to the old style, click "Classic" at the top right. The video player page is unaffected.

## Known limitations

- The macOS version is not notarized by Apple and the Windows version is not code-signed; the first time you open them, allow them as described above.
- macOS only has an Apple Silicon version for now, no Intel version; Windows only has an x64 version (Windows on ARM can run it through the built-in emulation).
- AI recognition on Windows runs on the CPU without GPU acceleration, slower than on a Mac; a smaller model is recommended.
- The weather theme on Windows can only locate you approximately from the network (the system location service isn't used); if the location is off, choose a city in Settings.
- Windows doesn't let apps make themselves the default player: click "Open System Settings" under "Settings > Library > File associations" and choose LightPlayer in Windows' "Default apps".
- Playing some videos (e.g. HEVC) on Windows may need live conversion, using more CPU than on a Mac.
- When a file is opened by double-clicking it in Finder, macOS itself may add it to "Recent Items"; this is outside private browsing's control.
- AI recognition needs a model download the first time (the recommended model is about 550 MB); a mirror for mainland China can be chosen in Settings.
- The bundled ffmpeg is a GPL build, for personal use only.
- Picture subtitles such as PGS and VobSub are not supported yet.
