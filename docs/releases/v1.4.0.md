# LightPlayer 1.4.0

新增播放器样式 Flow：仿照早年 Coverflow 的封面墙，左右翻看播放列表。

**首个 Windows 版本**：LightPlayer 现在同时提供 macOS 和 Windows 版本，功能基本一致。

## 下载与安装

### macOS

- 适用于 **Apple Silicon（M 系列芯片）** 的 Mac，需要 **macOS 12** 或更高版本。
- 下载下方的 `LightPlayer_1.4.0_aarch64.dmg`，打开后把 LightPlayer 拖进“应用程序”（可直接覆盖旧版本，媒体库和设置会保留）。
- 本版本未经 Apple 公证。首次打开如果提示“已损坏”或“无法验证开发者”，请在“应用程序”中右键 LightPlayer 选择“打开”，或在终端执行：

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- 适用于 **Windows 10 / 11（64 位）**。
- **安装版（推荐）**：下载 `LightPlayer_1.4.0_x64-setup.exe` 并运行，装在当前用户下，不需要管理员权限，开始菜单里会有 LightPlayer，可以在“设置 > 应用”中卸载。
- **便携版**：下载 `LightPlayer_1.4.0_x64_portable.zip`，解压后运行文件夹里的 `LightPlayer.exe`（请保留同目录的 `ffmpeg.exe` 和 `ffprobe.exe`）。
- 安装程序未经代码签名。如果出现“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。
- 需要 Microsoft Edge WebView2 运行时：Windows 11 和较新的 Windows 10 已自带；没有的话，安装版会自动下载安装，便携版请先从微软官网安装。

## 新功能

- **Windows 版本**
  - 窗口使用和 macOS 版一致的样式，右上角是最小化、最大化和关闭按钮。拖动顶栏可以移动窗口，双击顶栏最大化。
  - 快捷键里的 ⌘ 在 Windows 上对应 Ctrl，例如 Ctrl+O 打开文件、Ctrl+L 媒体库、Ctrl+Shift+N 无痕浏览。按钮提示和“设置 > 快捷键”中也会显示 Ctrl。
  - 关闭窗口后继续在后台播放：单击任务栏右侧通知区域中的 LightPlayer 图标打开窗口，右键图标可以播放 / 暂停、切歌或退出。
  - 支持键盘上的媒体键，以及调节音量时弹出的系统媒体浮窗（显示歌名和封面，可以播放 / 暂停、切歌）。
  - 在文件上右键“打开方式”可以选择 LightPlayer。LightPlayer 已经在运行时，双击文件会在原窗口中打开，不会再开一个新窗口。
  - 媒体库和播放列表中的“在文件资源管理器中显示”“移到回收站”都可以使用。
- **播放器样式 Flow**：播放音乐时，点播放页右上角的“Flow”按钮，或在“设置 > 外观 > 播放器样式”中选择“Flow”。
  - 播放列表里的歌以 3D 封面墙排开：正在播放的歌正对着你，左右两侧的封面倾斜叠放，下方带镜面倒影；切歌时封面会滑到中间。
  - 用滚轮、左右拖动封面，或拖动下方的滚动条翻看列表。
  - 点两侧的封面先把它转到中间，再点一下（或直接双击任意封面）就会播放这首歌。
  - 正在播放的歌居中时，下方会显示当前和下一句歌词，点击封面或歌名进入歌词页。
  - 翻看别的歌后停手几秒，会自动回到正在播放的那首。
  - 跟随当前的浅色、深色、天气或背景图主题；本地歌曲显示内嵌或文件夹里的封面，网易云歌曲显示专辑封面。
  - 想换回原来的样式，点右上角的“经典”即可。视频播放页不受影响。

## 已知限制

- macOS 版未经 Apple 公证，Windows 版未经代码签名，首次打开需要按上面的方法放行。
- macOS 暂时只提供 Apple Silicon 版本，没有 Intel 版本；Windows 只提供 x64 版本（ARM 版 Windows 可以通过系统自带的转译运行）。
- Windows 版的 AI 识别使用 CPU，没有 GPU 加速，比 Mac 慢，建议用较小的模型。
- Windows 版的天气主题只能按网络大致确定位置（不使用系统定位）；位置不准时请在设置中指定城市。
- Windows 不允许程序自己设为默认播放器：请在“设置 > 媒体库 > 文件关联”中点“打开系统设置”，在 Windows 的“默认应用”里选择 LightPlayer。
- Windows 版播放部分视频（例如 HEVC）时可能需要实时转换，CPU 占用比 Mac 版高。
- 从访达双击打开文件时，macOS 自己可能会把它加入“最近使用的项目”，这不受无痕浏览模式控制。
- AI 识别第一次使用需要下载模型（推荐模型约 550 MB），可以在设置中切换到国内镜像。
- 内置的 ffmpeg 是 GPL 构建，仅供个人使用。
- 暂不支持 PGS、VobSub 等图形字幕。
