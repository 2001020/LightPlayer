# LightPlayer 1.5.0

[简体中文](v1.5.0.md) | English

While playing a NetEase Cloud Music song you can now read its NetEase comments. The macOS and Windows versions are updated together.

## Download and install

### macOS

- For Macs with **Apple Silicon (M-series chips)**, running **macOS 12** or later.
- Download `LightPlayer_1.5.0_aarch64.dmg` below, open it and drag LightPlayer into Applications (it can replace the old version; your library and settings are kept).
- This version is not notarized by Apple. If macOS says it is "damaged" or the developer "can't be verified" the first time you open it, right-click LightPlayer in Applications and choose "Open", or run in Terminal:

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- For **Windows 10 / 11 (64-bit)**.
- **Installer (recommended)**: download `LightPlayer_1.5.0_x64-setup.exe` and run it. It installs for the current user without administrator rights, adds LightPlayer to the Start menu, and can be uninstalled under "Settings > Apps".
- **Portable**: download `LightPlayer_1.5.0_x64_portable.zip`, unzip it and run `LightPlayer.exe` in the folder (keep `ffmpeg.exe` and `ffprobe.exe` next to it).
- The installer is not code-signed. If you see "Windows protected your PC", click "More info", then "Run anyway".
- The Microsoft Edge WebView2 runtime is needed: Windows 11 and recent Windows 10 include it; otherwise the installer downloads and installs it, and for the portable version please install it from Microsoft's website first.

## New features

- **NetEase comments** (NetEase songs only)
  - While a NetEase song plays, a comments button appears at the right of the playback bar, and a tag such as "Comments 12.3K" shows under the title on the player page. Click either, or press `C`, to open the comments on the right; press `C` again, press `Esc` or click the close button at the top right to hide them.
  - The comments have "Popular" and "Latest" tabs and show the total count. Each comment shows the avatar, nickname, text, likes, time posted and IP location; a reply includes the comment it answers (noting when the original was deleted).
  - Comments with threaded replies show "Show N replies" below them; click to read them, and load more when there are many.
  - Scrolling to the bottom of the list loads more comments automatically.
  - When the song changes, the comments switch to the new song's; for local songs the comments button and panel hide automatically.
  - They can be opened on the player page, the lyrics page and in the library, and in the Flow style too; they follow the light, dark, weather and background image themes.
  - The comments are read-only; posting, liking and replying aren't supported yet.

## Known limitations

- Like the other NetEase features, the comments use unofficial web APIs that may stop working at any time; when NetEase Cloud Music applies risk control they may fail to load for a while; click "Retry" later.

- The macOS version is not notarized by Apple and the Windows version is not code-signed; the first time you open them, allow them as described above.
- macOS only has an Apple Silicon version for now, no Intel version; Windows only has an x64 version (Windows on ARM can run it through the built-in emulation).
- AI recognition on Windows runs on the CPU without GPU acceleration, slower than on a Mac; a smaller model is recommended.
- The weather theme on Windows can only locate you approximately from the network (the system location service isn't used); if the location is off, choose a city in Settings.
- Windows doesn't let apps make themselves the default player: click "Open System Settings" under "Settings > Library > File associations" and choose LightPlayer in Windows' "Default apps".
- Playing some videos (e.g. HEVC) on Windows may need live conversion, using more CPU than on a Mac.
- When a file is opened by double-clicking it in Finder, macOS itself may add it to "Recent Items"; this is outside private browsing's control.
- AI recognition needs a model download the first time (the recommended model is about 550 MB); a mirror for mainland China can be chosen in Settings.
- The bundled ffmpeg is a GPL build, for personal use only.
- Picture subtitles such as PGS and VobSub are not supported yet.
