# LightPlayer 1.6.0

[简体中文](v1.6.0.md) | English

The 1.6.0 release brings **plugins**, a **custom player page** (with a vinyl record look), **interface languages** and **in-app automatic updates**, and the heart on NetEase Cloud Music songs now syncs with the account's liked songs. The macOS and Windows versions are updated together.

## Download and install

### macOS

- For Macs with **Apple Silicon (M-series chips)**, running **macOS 12** or later.
- Download `LightPlayer_1.6.0_aarch64.dmg` below, open it and drag LightPlayer into Applications (it can replace the old version; your library and settings are kept).
- This version is not notarized by Apple. If macOS says it is "damaged" or the developer "can't be verified" the first time you open it, right-click LightPlayer in Applications and choose "Open", or run in Terminal:

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- For **Windows 10 / 11 (64-bit)**.
- **Installer (recommended)**: download `LightPlayer_1.6.0_x64-setup.exe` and run it. It installs for the current user without administrator rights, adds LightPlayer to the Start menu, and can be uninstalled under "Settings > Apps".
- **Portable**: download `LightPlayer_1.6.0_x64_portable.zip`, unzip it and run `LightPlayer.exe` in the folder (keep `ffmpeg.exe` and `ffprobe.exe` next to it).
- The installer is not code-signed. If you see "Windows protected your PC", click "More info", then "Run anyway".
- The Microsoft Edge WebView2 runtime is needed: Windows 11 and recent Windows 10 include it; otherwise the installer downloads and installs it, and for the portable version please install it from Microsoft's website first.

## New features

- **Plugins** (Settings > Plugins)
  - Plugins can change the layout, styles, text and fonts of the interface and the look and settings of the player and lyrics pages, and can ship complete player page layouts; plugins can't run code, so installing third-party plugins is safe.
  - Install a `.lpplugin` file or a plugin folder and turn it on; adjust the options a plugin offers and the order several plugins stack in. If a plugin breaks the interface, press `⌥⇧⌘P` (Windows: `Ctrl+Alt+Shift+P`) for safe mode, which turns all plugins off for the moment.
  - See the [plugin development standard](https://github.com/2001020/LightPlayer/blob/HEAD/docs/plugins/README.en.md) (with a JSON Schema, stable area anchors, page state attributes and public CSS variables) and the four example plugins (the `.lpplugin` assets): **Minimal player**, **Serif lyrics**, **English UI** and **Retro turntable**.
- **Custom player page** (the **Layout** button at the top right of the player page, or Settings > Appearance > Player page layout)
  - **Cover shape**: square (with adjustable corners — round at the maximum) or a **vinyl record**. The record spins while playing and stops at its current angle when paused, the tonearm lowers and lifts with playback, with grooves and sheen; each effect can be adjusted on its own.
  - **Three built-in layouts**: Default (as before), Turntable, and Vinyl + two columns.
  - **Visual editing**: drag elements to move and resize them, drag the dot above an element to rotate it, with snapping; the panel on the right sets the position, size, rotation, opacity, text style and cover effects precisely; each element can have an entrance animation on song change; add text, images, clocks, a progress bar or ring, play time and more; with undo / redo, duplicate and keyboard nudging.
  - Layouts can be edited with no song playing, using a sample song.
  - Layouts scale proportionally and look the same at any window size and in full screen; keep several of your own, switch at any time, or **export one as a plugin** to share.
- **Interface languages** (Settings > Appearance > Language)
  - Choose 简体中文, 繁體中文, English, 日本語, 한국어, or "Same as system"; the change applies at once.
  - New installs follow the system language (English when it isn't one of these); people upgrading from an earlier version keep Simplified Chinese.
  - The menu bar / notification area menu, the open / save / confirmation dialogs, date and number formats and weather place names follow the chosen language too; lyrics, song titles, comments and other content are not translated.
  - The repository's documents all have English versions, and release notes include both Chinese and English, with the update window showing the one matching the interface language.
- **Automatic updates** (Settings > About)
  - Checks GitHub for a new version at launch and every 12 hours, shows the release notes, downloads with one click (size and SHA-256 checked), installs and reopens. Works for the macOS version and the Windows installer and portable versions.
  - Automatic checks can be turned off, and you can choose whether to receive pre-releases.
- **Heart for NetEase Cloud Music songs**: while a NetEase song plays, the heart at the bottom left of the playback bar adds it to the NetEase account's "My liked songs", and clicking again removes it, just like NetEase's own apps.
  - In the library, every song in NetEase playlists, daily picks and search results also has a heart showing whether it is in "My liked songs", and the context menu can add or remove it too.
  - Clicking the heart while signed out says so and opens the sign-in window.

## Other changes

- Clicking the song info at the bottom left of the playback bar now goes to the player page first; clicking it again on the player page opens the lyrics page (and on the lyrics page it goes back to the player page). `Y` still opens the lyrics directly.
- The Flow style (cover wall) no longer shows the two small lyric lines under the title, for a cleaner look; clicking the cover still opens the lyrics page.

## Compared with 1.6.0 Beta 4

- Adds the NetEase heart sync, the new click order of the playback bar's song info and the Flow style change (see above).
- After a beta user updates to the final release, they receive only final releases from then on unless they chose otherwise under "Settings > About"; to keep trying pre-releases, turn on "Include pre-releases".

## Known limitations

- Upgrading from 1.5.0 or earlier needs a manual download (those versions have no automatic updates yet); later versions all update in the app. Users of 1.6.0 Beta 1 to Beta 4 can update to this version in the app.
- Automatic updates need access to GitHub (api.github.com and github.com).
- The NetEase Cloud Music features (including the heart and comments) use unofficial web APIs that may stop working at any time; when NetEase Cloud Music applies risk control they may be unavailable for a while, so try again later.
- Player page layouts only apply to the "Classic" audio style; the Flow style and the video player page are unchanged.
- The interface was translated by the developer; some wording may not be idiomatic, and feedback is welcome.
- The names and descriptions of the example plugins, and the NetEase Cloud Music sign-in web page, are still in Chinese; with Traditional Chinese, weather place names are in Simplified Chinese.
- Plugin text replacement only applies to LightPlayer's own interface (including the menu bar / notification area menu and the open, save and confirmation dialogs); the system's own text and notifications aren't replaced.
- Plugins can only use resources in their own folder, not images or fonts from the web.
- The macOS version is not notarized by Apple and the Windows version is not code-signed; the first time you open them, allow them as described above.
- macOS only has an Apple Silicon version for now, no Intel version; Windows only has an x64 version (Windows on ARM can run it through the built-in emulation).
- AI recognition on Windows runs on the CPU without GPU acceleration, slower than on a Mac; a smaller model is recommended.
- The weather theme on Windows can only locate you approximately from the network (the system location service isn't used); if the location is off, choose a city in Settings.
- Windows doesn't let apps make themselves the default player: click "Open System Settings" under "Settings > Library > File associations" and choose LightPlayer in Windows' "Default apps".
- Playing some videos (e.g. HEVC) on Windows may need live conversion, using more CPU than on a Mac.
- When a file is opened by double-clicking it in Finder, macOS itself may add it to "Recent Items"; this is outside private browsing's control.
- AI recognition needs a model download the first time (the recommended model is about 550 MB); a mirror for mainland China can be chosen in Settings.
- The bundled ffmpeg is a GPL build, for personal use only.
- Picture subtitles such as PGS and VobSub are not supported yet.
