# LightPlayer 1.6.0

简体中文 | [English](v1.6.0.en.md)

1.6.0 正式版带来**插件**、**自定义播放页**（含黑胶唱片效果）、**多语言界面**和 **App 内自动更新**，网易云音乐的红心现在会同步到账号的“我喜欢的音乐”。macOS 和 Windows 版本同时更新。

## 下载与安装

### macOS

- 适用于 **Apple Silicon（M 系列芯片）** 的 Mac，需要 **macOS 12** 或更高版本。
- 下载下方的 `LightPlayer_1.6.0_aarch64.dmg`，打开后把 LightPlayer 拖进“应用程序”（可直接覆盖旧版本，媒体库和设置会保留）。
- 本版本未经 Apple 公证。首次打开如果提示“已损坏”或“无法验证开发者”，请在“应用程序”中右键 LightPlayer 选择“打开”，或在终端执行：

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- 适用于 **Windows 10 / 11（64 位）**。
- **安装版（推荐）**：下载 `LightPlayer_1.6.0_x64-setup.exe` 并运行，装在当前用户下，不需要管理员权限，开始菜单里会有 LightPlayer，可以在“设置 > 应用”中卸载。
- **便携版**：下载 `LightPlayer_1.6.0_x64_portable.zip`，解压后运行文件夹里的 `LightPlayer.exe`（请保留同目录的 `ffmpeg.exe` 和 `ffprobe.exe`）。
- 安装程序未经代码签名。如果出现“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。
- 需要 Microsoft Edge WebView2 运行时：Windows 11 和较新的 Windows 10 已自带；没有的话，安装版会自动下载安装，便携版请先从微软官网安装。

## 新功能

- **插件**（设置 > 插件）
  - 插件可以改变界面布局、样式、文字和字体，以及播放页和歌词页的样式与设置，还可以附带完整的播放页布局；插件不能运行代码，安装第三方插件是安全的。
  - 安装 `.lpplugin` 文件或插件文件夹后即可启用，可以调整插件提供的选项、调整多个插件的叠加顺序；某个插件把界面改乱时，按 `⌥⇧⌘P`（Windows：`Ctrl+Alt+Shift+P`）进入安全模式，临时停用全部插件。
  - 附[插件开发标准](https://github.com/2001020/LightPlayer/blob/HEAD/docs/plugins/README.md)（含 JSON Schema、稳定的区域锚点、页面状态属性和公开 CSS 变量），以及四个示例插件（附件中的 `.lpplugin`）：**极简播放页**、**宋体歌词**、**English UI**、**复古唱机**。
- **自定义播放页**（播放页右上角的 **布局** 按钮，或 设置 > 外观 > 播放页布局）
  - **封面形状**：方形（可调圆角，调到最大就是圆形）或**黑胶唱片**。唱片播放时转动、暂停时停在当前角度，唱臂随播放落下、抬起，带有唱片纹路和光泽，各项效果都可以单独调整。
  - **内置三种布局**：默认（和以前一样）、黑胶唱片机、唱片 + 左右分栏。
  - **可视化编辑**：拖动元素改变位置和大小，拖动元素上方的圆点旋转，自动吸附对齐；右侧面板可以精确设置位置、大小、旋转、不透明度、文字样式和封面效果；每个元素可以设置切歌时的入场动画；可以添加文字、图片、时钟、进度条 / 进度环、播放时间等元素；支持撤销 / 重做、复制和键盘微调。
  - 没有播放歌曲时也能编辑，会用一首示例歌曲显示播放页。
  - 布局按比例缩放，任何窗口大小和全屏下都保持相同的样子；可以保存多个自己的布局，随时切换，也可以**导出为插件**发给别人。
- **界面语言**（设置 > 外观 > 语言）
  - 可选简体中文、繁體中文、English、日本語、한국어，或“跟随系统”，切换后立即生效。
  - 新安装时默认跟随系统语言（不在上面几种之内时使用英文）；从旧版本升级的用户保持简体中文。
  - 菜单栏 / 通知区域图标的菜单、打开 / 保存 / 确认对话框、日期和数字格式、天气地名也会跟随所选语言；歌词、歌名、评论等内容不翻译。
  - 仓库中的文档都有英文版，发布说明同时包含中文和英文，更新窗口按界面语言显示其中一种。
- **自动更新**（设置 > 关于）
  - 启动时和每隔 12 小时检查 GitHub 上的新版本，显示更新说明，一键下载（校验大小和 SHA-256）并安装，完成后自动重新打开。macOS 版、Windows 安装版和便携版都支持。
  - 可以关闭自动检查，也可以选择是否接收预发布版本。
- **网易云音乐的红心**：播放网易云歌曲时，点播放栏左下角的红心，会把这首歌添加到网易云账号的“我喜欢的音乐”，再点一次取消，和网易云音乐自己的客户端一致。
  - 媒体库中网易云歌单、每日推荐和搜索结果的每首歌右侧也有红心，显示这首歌是否已在“我喜欢的音乐”中，右键菜单中同样可以添加或移除。
  - 没有登录时点红心，会提示并打开登录窗口。

## 其他变化

- 点击播放栏左下角的歌曲信息时，会先回到播放页；在播放页再点一次才打开歌词页（在歌词页点击则回到播放页）。按 `Y` 仍然可以直接打开歌词。
- Flow 样式（封面墙）的歌名下方不再显示两行小歌词，画面更简洁；点击封面仍可打开歌词页。

## 与 1.6.0 Beta 4 相比

- 新增网易云音乐的红心同步、播放栏歌曲信息的点击顺序和 Flow 样式的变化（见上）。
- 已安装 Beta 版的用户更新到正式版后，如果在“设置 > 关于”中没有手动选择，之后只会收到正式版更新；想继续试用预发布版本，请打开“包括预发布版本”。

## 已知限制

- 从 1.5.0 及更早版本升级需要手动下载安装（这些版本还没有自动更新）；之后的版本都可以在 App 内更新。已安装 1.6.0 Beta 1 到 Beta 4 的用户可以在 App 内直接更新到本版本。
- 自动更新需要能访问 GitHub（api.github.com 和 github.com）。
- 网易云音乐的功能（包括红心和评论区）使用网页版的非官方接口，随时可能失效；网易云音乐风控时可能暂时无法使用，稍后再试即可。
- 播放页布局只作用于音频的“经典”样式；Flow 样式和视频播放页不变。
- 界面翻译由开发者完成，个别用语可能不够地道，欢迎反馈。
- 示例插件的名称和说明、网易云音乐登录网页仍为中文；繁體中文界面下，天气地名使用简体中文。
- 插件的文字替换只作用于 LightPlayer 自己的界面（包括菜单栏 / 通知区域菜单和打开、保存、确认对话框），系统自身的文字和通知不会被替换。
- 插件只能使用自己文件夹中的资源，不能引用网络上的图片或字体。
- macOS 版未经 Apple 公证，Windows 版未经代码签名，首次打开需要按上面的方法放行。
- macOS 暂时只提供 Apple Silicon 版本，没有 Intel 版本；Windows 只提供 x64 版本（ARM 版 Windows 可以通过系统自带的转译运行）。
- Windows 版的 AI 识别使用 CPU，没有 GPU 加速，比 Mac 慢，建议用较小的模型。
- Windows 版的天气主题只能按网络大致确定位置（不使用系统定位）；位置不准时请在设置中指定城市。
- Windows 不允许程序自己设为默认播放器：请在“设置 > 媒体库 > 文件关联”中点“打开系统设置”，在 Windows 的“默认应用”里选择 LightPlayer。
- Windows 版播放部分视频（例如 HEVC）时可能需要实时转换，CPU 占用比 Mac 版高。
- 从访达双击打开文件时，macOS 自己可能会把它加入“最近使用的项目”，这不受无痕浏览模式控制。
- AI 识别第一次使用需要下载模型（推荐模型约 550 MB），可以在设置中切换到国内镜像。
- 内置的 ffmpeg 是 GPL 构建，仅供个人使用。
- 暂不支持 PGS、VobSub 等图形字幕。
