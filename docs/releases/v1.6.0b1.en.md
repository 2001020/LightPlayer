# LightPlayer 1.6.0 Beta 1

[简体中文](v1.6.0b1.md) | English

This is a **pre-release** of 1.6.0 with two new features, for macOS and Windows together:

- **Plugins**: change the layout, styles, text and fonts of the interface, and the look and settings of the player and lyrics pages. The [plugin development standard](https://github.com/2001020/LightPlayer/blob/HEAD/docs/plugins/README.en.md) is published alongside.
- **Automatic updates**: checks GitHub for new versions and downloads and installs them with one click.

## Download and install

### macOS

- For Macs with **Apple Silicon (M-series chips)**, running **macOS 12** or later.
- Download `LightPlayer_1.6.0b1_aarch64.dmg` below, open it and drag LightPlayer into Applications (it can replace the old version; your library and settings are kept).
- This version is not notarized by Apple. If macOS says it is "damaged" or the developer "can't be verified" the first time you open it, right-click LightPlayer in Applications and choose "Open", or run in Terminal:

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- For **Windows 10 / 11 (64-bit)**.
- **Installer (recommended)**: download `LightPlayer_1.6.0b1_x64-setup.exe` and run it. It installs for the current user without administrator rights, adds LightPlayer to the Start menu, and can be uninstalled under "Settings > Apps".
- **Portable**: download `LightPlayer_1.6.0b1_x64_portable.zip`, unzip it and run `LightPlayer.exe` in the folder (keep `ffmpeg.exe` and `ffprobe.exe` next to it).
- The installer is not code-signed. If you see "Windows protected your PC", click "More info", then "Run anyway".
- The Microsoft Edge WebView2 runtime is needed: Windows 11 and recent Windows 10 include it; otherwise the installer downloads and installs it, and for the portable version please install it from Microsoft's website first.

## New features

- **Plugins** (Settings > Plugins)
  - Plugins can:
    - change the layout of the interface, e.g. put the cover above the song title or hide some buttons
    - change the styles of elements, e.g. corner radii, colors, shadows, background images
    - replace interface text, e.g. switch the interface to English
    - change fonts, using system fonts or font files shipped with the plugin
    - change the look and settings of the player and lyrics pages, e.g. the lyrics font, line spacing, alignment, size and current-line effect, the cover size, the player style
  - Install: click "Install plugin package…" and choose a `.lpplugin` file, or use "Install from folder…". Installing a new version of a plugin asks to replace it, keeping its switch state and options.
  - Each plugin has a switch; enabling and disabling take effect at once, without a restart. Several plugins can be on together; order them with move up / move down, and the lower one wins.
  - Plugins can offer options (sliders, colors, selects, switches), adjusted under "Plugin options" on the plugin's card, with changes applied live.
  - A plugin can change some settings when enabled (e.g. left-aligned lyrics, the lyrics size); they are restored when it is disabled, except settings you changed yourself in the meantime.
  - Plugins **cannot run code**: they hold only style sheets, fonts, images and text tables, and can't go online, so installing someone else's plugin is safe. A plugin that doesn't follow the standard can't be enabled, and its card shows why.
  - **Safe mode**: if a plugin messes up the interface, press `⌥⇧⌘P` (Windows: `Ctrl+Alt+Shift+P`) to turn off all plugins for now; press again to bring them back.
  - Plugins apply to the desktop lyrics window too (e.g. the lyrics font).
- **Example plugins**: the assets below include three examples you can install directly, which are also a reference for making plugins:
  - `example.minimal-player.lpplugin` (**Minimal player**): a larger cover above the song title, the format tag and album name hidden, an optional slimmer playback bar. Adjustable layout, cover size and corner radius.
  - `example.serif-lyrics.lpplugin` (**Serif lyrics**): Song or Kai lyrics, left-aligned at size 30, with a glowing current line. Adjustable glow strength and color.
  - `example.english-ui.lpplugin` (**English UI**): replaces the main interface text with English.
- **Plugin development standard**: describes the package structure, every field of `manifest.json`, the public interface plugins can rely on (area anchors, page state attributes, CSS variables), text replacement rules, fonts, adjustable settings, option types, packaging and debugging. A JSON Schema is included, so editors can complete and check `manifest.json`.
- **Automatic updates** (Settings > About > Updates)
  - Checks GitHub for a new version at launch and every 12 hours; when there is one, an update window shows the version and release notes.
  - "Update now" downloads in the app (with progress, cancelable), checks the file size and SHA-256, then installs automatically and reopens LightPlayer, keeping your library and settings:
    - macOS: replaces LightPlayer in Applications.
    - Windows installer: runs the new installer silently in the background, into the same place.
    - Windows portable: updates the files in the portable version's folder.
  - You can also choose "Later" (an update button shows in the title bar) or "Skip this version" (no more automatic reminders for it).
  - In Settings you can "Check for updates" by hand, turn off automatic checks, or choose whether to include pre-releases. They are included by default when the current version is a pre-release; otherwise only final releases are offered.
  - If an automatic install doesn't finish (e.g. without write permission), LightPlayer stays on the old version and asks you to download manually the next time it opens.
  - The About page now shows the full version number (e.g. 1.6.0b1).

## Other improvements

- With the weather theme, the current line on the lyrics page now shows at full brightness (before, it was translucent like the other lines).

## Known limitations

- Automatic updates start with this version: upgrading from 1.5.0 or earlier to this version still needs a manual download; later versions can then be updated in the app with one click.
- Automatic updates need access to GitHub (api.github.com and github.com).
- This is a pre-release; the plugin standard (`manifestVersion: 1`) may still be adjusted from feedback before the final release, and will stay compatible after it.
- Plugin text replacement only applies to the interface LightPlayer draws itself; text in the menu bar / notification area menu, system dialogs and notifications isn't replaced.
- Plugins can only use resources in their own folder, not images or fonts from the web.
- The macOS version is not notarized by Apple and the Windows version is not code-signed; the first time you open them, allow them as described above.
- macOS only has an Apple Silicon version for now, no Intel version; Windows only has an x64 version (Windows on ARM can run it through the built-in emulation).
- AI recognition on Windows runs on the CPU without GPU acceleration, slower than on a Mac; a smaller model is recommended.
- The weather theme on Windows can only locate you approximately from the network (the system location service isn't used); if the location is off, choose a city in Settings.
- Windows doesn't let apps make themselves the default player: click "Open System Settings" under "Settings > Library > File associations" and choose LightPlayer in Windows' "Default apps".
- Playing some videos (e.g. HEVC) on Windows may need live conversion, using more CPU than on a Mac.
- When a file is opened by double-clicking it in Finder, macOS itself may add it to "Recent Items"; this is outside private browsing's control.
- AI recognition needs a model download the first time (the recommended model is about 550 MB); a mirror for mainland China can be chosen in Settings.
- The bundled ffmpeg is a GPL build, for personal use only.
- Picture subtitles such as PGS and VobSub are not supported yet.
