# LightPlayer 1.6.0 Beta 1

简体中文 | [English](v1.6.0b1.en.md)

这是 1.6.0 的**预发布版本**，新增两项功能，macOS 和 Windows 版本同时更新：

- **插件**：可以改变界面的布局、样式、文字和字体，以及播放页和歌词页的样式与设置。同时发布[插件开发标准](https://github.com/2001020/LightPlayer/blob/HEAD/docs/plugins/README.md)。
- **自动更新**：从 GitHub 检查新版本，一键下载安装。

## 下载与安装

### macOS

- 适用于 **Apple Silicon（M 系列芯片）** 的 Mac，需要 **macOS 12** 或更高版本。
- 下载下方的 `LightPlayer_1.6.0b1_aarch64.dmg`，打开后把 LightPlayer 拖进“应用程序”（可直接覆盖旧版本，媒体库和设置会保留）。
- 本版本未经 Apple 公证。首次打开如果提示“已损坏”或“无法验证开发者”，请在“应用程序”中右键 LightPlayer 选择“打开”，或在终端执行：

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- 适用于 **Windows 10 / 11（64 位）**。
- **安装版（推荐）**：下载 `LightPlayer_1.6.0b1_x64-setup.exe` 并运行，装在当前用户下，不需要管理员权限，开始菜单里会有 LightPlayer，可以在“设置 > 应用”中卸载。
- **便携版**：下载 `LightPlayer_1.6.0b1_x64_portable.zip`，解压后运行文件夹里的 `LightPlayer.exe`（请保留同目录的 `ffmpeg.exe` 和 `ffprobe.exe`）。
- 安装程序未经代码签名。如果出现“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。
- 需要 Microsoft Edge WebView2 运行时：Windows 11 和较新的 Windows 10 已自带；没有的话，安装版会自动下载安装，便携版请先从微软官网安装。

## 新功能

- **插件**（设置 > 插件）
  - 插件可以：
    - 改变界面布局，例如把封面放到歌名上方、隐藏某些按钮
    - 改变元素样式，例如圆角、颜色、阴影、背景图片
    - 替换界面文字，例如把界面改成英文
    - 更换字体，可以使用系统字体，也可以用插件自带的字体文件
    - 改变播放页和歌词页的样式与设置，例如歌词字体、行距、对齐、字号和当前行效果，封面大小，播放器样式
  - 安装：点“安装插件包…”选择 `.lpplugin` 文件，或者“从文件夹安装…”。安装同一个插件的新版本时会提示替换，原有的开关状态和选项都会保留。
  - 每个插件都有开关，启用、停用立即生效，不需要重启。多个插件可以同时启用，用上移 / 下移调整先后，靠下的插件优先。
  - 插件可以提供可调选项（滑块、颜色、选择、开关），在插件卡片的“插件选项”中调整，修改实时生效。
  - 插件可以在启用时调整部分设置（例如歌词左对齐、字号），停用后自动恢复原来的值；你在启用期间自己改过的设置会保留。
  - 插件**不能运行代码**，只包含样式表、字体、图片和文字替换表，也不能联网，所以安装别人做的插件是安全的。不符合标准的插件无法启用，卡片上会显示原因。
  - **安全模式**：插件把界面改乱时，按 `⌥⇧⌘P`（Windows：`Ctrl+Alt+Shift+P`）临时停用所有插件，再按一次恢复。
  - 桌面歌词窗口同样会应用插件（例如歌词字体）。
- **示例插件**：下方附件中有三个可以直接安装的示例，也是制作插件的参考：
  - `example.minimal-player.lpplugin`（**极简播放页**）：封面放大并放在歌名上方，隐藏格式标签和专辑名，可选精简播放栏。可调布局、封面大小和圆角。
  - `example.serif-lyrics.lpplugin`（**宋体歌词**）：宋体或楷体歌词，左对齐、30 号字，当前行发光。可调发光强度和颜色。
  - `example.english-ui.lpplugin`（**English UI**）：把主要界面文字换成英文。
- **插件开发标准**：说明插件包结构、`manifest.json` 各字段、可以依赖的公开接口（区域锚点、页面状态属性、CSS 变量）、文字替换规则、字体、可调整的设置、选项类型、打包和调试方法。附带 JSON Schema，编辑器中可以自动补全和检查 `manifest.json`。
- **自动更新**（设置 > 关于 > 更新）
  - 启动时和每隔 12 小时检查 GitHub 上的新版本，有新版本时弹出更新窗口，显示版本号和更新说明。
  - 点“立即更新”后在 App 内下载（显示进度，可以取消），下载完成后校验文件大小和 SHA-256，然后自动安装并重新打开 LightPlayer，媒体库和设置都会保留：
    - macOS：替换“应用程序”中的 LightPlayer。
    - Windows 安装版：在后台静默运行新版安装程序，装到原来的位置。
    - Windows 便携版：更新便携版所在文件夹中的文件。
  - 也可以选“以后再说”（标题栏会显示更新按钮）或“跳过此版本”（不再自动提示这个版本）。
  - 可以在设置中手动“检查更新”、关闭自动检查，或选择是否包括预发布版本。当前是预发布版本时默认包括，否则只提示正式版。
  - 自动安装没有完成时（例如没有写入权限），LightPlayer 会保持原来的版本，下次打开时提示你手动下载。
  - 关于页现在显示完整的版本号（例如 1.6.0b1）。

## 其他改进

- 天气主题下，歌词页当前行改为完整亮度显示（之前和其他行一样是半透明的）。

## 已知限制

- 自动更新从这个版本开始提供：从 1.5.0 及更早版本升级到本版本，仍需要手动下载安装；之后的新版本就可以在 App 内一键更新。
- 自动更新需要能访问 GitHub（api.github.com 和 github.com）。
- 这是预发布版本，插件标准（`manifestVersion: 1`）在正式版前仍可能根据反馈微调；正式版发布后会保持兼容。
- 插件的文字替换只作用于 LightPlayer 自己绘制的界面，菜单栏 / 通知区域菜单、系统对话框和通知中的文字不会被替换。
- 插件只能使用自己文件夹中的资源，不能引用网络上的图片或字体。
- macOS 版未经 Apple 公证，Windows 版未经代码签名，首次打开需要按上面的方法放行。
- macOS 暂时只提供 Apple Silicon 版本，没有 Intel 版本；Windows 只提供 x64 版本（ARM 版 Windows 可以通过系统自带的转译运行）。
- Windows 版的 AI 识别使用 CPU，没有 GPU 加速，比 Mac 慢，建议用较小的模型。
- Windows 版的天气主题只能按网络大致确定位置（不使用系统定位）；位置不准时请在设置中指定城市。
- Windows 不允许程序自己设为默认播放器：请在“设置 > 媒体库 > 文件关联”中点“打开系统设置”，在 Windows 的“默认应用”里选择 LightPlayer。
- Windows 版播放部分视频（例如 HEVC）时可能需要实时转换，CPU 占用比 Mac 版高。
- 从访达双击打开文件时，macOS 自己可能会把它加入“最近使用的项目”，这不受无痕浏览模式控制。
- AI 识别第一次使用需要下载模型（推荐模型约 550 MB），可以在设置中切换到国内镜像。
- 内置的 ffmpeg 是 GPL 构建，仅供个人使用。
- 暂不支持 PGS、VobSub 等图形字幕。
