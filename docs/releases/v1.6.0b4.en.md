# LightPlayer 1.6.0 Beta 4

[简体中文](v1.6.0b4.md) | English

This is the fourth **pre-release** of 1.6.0, adding **interface languages**: besides Simplified Chinese, the interface now comes in Traditional Chinese, English, Japanese and Korean. The documents in the repository also have English versions now. Everything from Beta 1 to Beta 3 is included.

## Download and install

### macOS

- For Macs with **Apple Silicon (M-series chips)**, running **macOS 12** or later.
- Download `LightPlayer_1.6.0b4_aarch64.dmg` below, open it and drag LightPlayer into Applications (it can replace the old version; your library and settings are kept).
- This version is not notarized by Apple. If macOS says it is "damaged" or the developer "can't be verified" the first time you open it, right-click LightPlayer in Applications and choose "Open", or run in Terminal:

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- For **Windows 10 / 11 (64-bit)**.
- **Installer (recommended)**: download `LightPlayer_1.6.0b4_x64-setup.exe` and run it. It installs for the current user without administrator rights, adds LightPlayer to the Start menu, and can be uninstalled under "Settings > Apps".
- **Portable**: download `LightPlayer_1.6.0b4_x64_portable.zip`, unzip it and run `LightPlayer.exe` in the folder (keep `ffmpeg.exe` and `ffprobe.exe` next to it).
- The installer is not code-signed. If you see "Windows protected your PC", click "More info", then "Run anyway".
- The Microsoft Edge WebView2 runtime is needed: Windows 11 and recent Windows 10 include it; otherwise the installer downloads and installs it, and for the portable version please install it from Microsoft's website first.

## New features

- **Interface languages** (Settings > Appearance > Language)
  - Choose 简体中文, 繁體中文, English, 日本語, 한국어, or "Same as system". The change applies at once, without a restart and without interrupting playback.
  - New installs follow the system language by default (English when the system language isn't one of these); people upgrading from an earlier version keep Simplified Chinese and can switch in Settings at any time.
  - The whole interface is translated, including button hints, context menus, dialogs, error messages and the desktop lyrics window; the menu of the menu bar / notification area icon and the titles and buttons of the open, save and confirmation dialogs follow the chosen language too.
  - Dates, times and numbers follow the language's conventions, e.g. comment times, recognition task times, the date in player page clocks, and counts such as "12K / 1.2万".
  - With English, Japanese or Korean, weather place names and city search results are in that language too.
  - From this version on, the update window shows the release notes in Chinese or English to match the interface language.
  - Lyrics, song titles, artists, albums, file names, playlist names, comments and other content are not translated.
- **English documentation**: the README, the development plan, the plugin development standard and the release notes of every version now have English versions (`*.en.md`), with a language switch at the top of each. Release notes from now on include both Chinese and English.
- **Plugin development standard**
  - New page state attribute `lang` (`zh-Hans` / `zh-Hant` / `en` / `ja` / `ko`) for styles that apply only in one language, e.g. `:root[lang="en"]`.
  - The originals in a plugin's text table are still the Simplified Chinese interface text, whatever language the user chooses; a plugin's entries win over the built-in language.
  - Plugin text replacement now also applies to the menu of the menu bar / notification area icon and to the titles and buttons of the open, save and confirmation dialogs.
  - The text a placeholder stands for is looked up again, so e.g. the error message in "保存失败：{a}" ("Save failed: {a}") is replaced too.

## What's in 1.6.0 Beta 3

- **Drag to rotate**: while editing a layout, drag the dot above the selected element to rotate it; it snaps near 0°, 45° and 90°, Shift rotates in 15° steps, and double-clicking the dot resets it.
- **Edit layouts with no song playing**: click "Edit…" under "Settings > Appearance > Player page layout" and the player page shows a sample song to edit with.

## What's in 1.6.0 Beta 2

- **Custom player page** (the **Layout** button at the top right of the player page, or Settings > Appearance > Player page layout)
  - **Cover shape**: square (with adjustable corners — round at the maximum) or a **vinyl record**. The record spins while playing and stops at its current angle when paused; the tonearm lowers onto the record while playing and lifts away when paused; with grooves and sheen. Spin speed, the cover's size on the record, the tonearm, grooves and shadow can each be turned on/off or adjusted.
  - **Three built-in layouts**:
    - **Default**: exactly as before.
    - **Turntable**: a big record in the middle, with the title, artist and lyrics below.
    - **Vinyl + two columns**: the record on the left, the title, artist, album and two lyric lines on the right.
  - **Visual editing**: choose "Edit layout…" to enter edit mode:
    - Drag elements to move them, and the small square at the bottom right to resize; they snap to the center lines and to other elements' alignment lines (hold ⌥ / Alt while dragging to turn snapping off).
    - The panel on the right sets the position, width, rotation and opacity precisely; the text's size, weight, font, color, alignment, letter spacing, italics and shadow; the cover's shape and record effects.
    - Each element can have an **entrance animation on song change**: fade in, slide up, down, left or right, zoom, blur in, with adjustable duration and delay; "Preview animation" shows it at once.
    - **Add new elements**: text (with the title, artist, album, play time, current time and more), images, clocks, a progress bar or ring, play time. The title, artist, album, tags and lyric preview can be hidden and shown again at any time.
    - Change the stacking order in the element list; undo / redo (⌘Z / ⇧⌘Z, Windows: Ctrl+Z / Ctrl+Shift+Z), arrow keys to nudge, ⌘D to duplicate, Delete to delete.
    - The settings panel can move to the other side, or be hidden to see the whole picture.
    - Click "Done" to save. Editing a built-in layout saves it as your own, leaving the original unchanged; "Cancel" discards the changes.
  - Layouts scale proportionally and look the same at any window size and in full screen.
  - Keep several layouts of your own, and switch, duplicate, rename or delete them from the "Layout" menu at any time.
  - **Export as plugin**: export your own layout (with the images it uses) as a `.lpplugin`; others install it under "Settings > Plugins" to use it.
- **Plugins can provide player page layouts**: the plugin development standard adds `layouts`, so a plugin can ship complete player page layouts, which appear under "From plugins" in the "Layout" menu once it is enabled. The standard describes the layout file format (with a JSON Schema) and adds layout-related area anchors (`player-layout`, `layout-item`, `vinyl`, `tonearm` and more) and the page state attribute `data-player-layout`.
- **New example plugin** `example.retro-turntable.lpplugin` (**Retro turntable**): the record on the left with a progress ring around it, the song info, lyrics and play time on the right, a clock and a sticker in the corners, with CSS fine-tuning the layout's elements. With the three earlier examples, the assets include four example plugins.

## What's in 1.6.0 Beta 1

- **Plugins**: change the layout, styles, text and fonts of the interface, and the look and settings of the player and lyrics pages; plugins can't run code. See the [plugin development standard](https://github.com/2001020/LightPlayer/blob/HEAD/docs/plugins/README.en.md).

## Known limitations

- Users of 1.6.0 Beta 1, Beta 2 or Beta 3 can update to this version in the app (Settings > About > Check for updates; pre-release versions receive later pre-releases by default); upgrading from 1.5.0 or earlier still needs a manual download.
- Automatic updates need access to GitHub (api.github.com and github.com).
- This is a pre-release; the plugin standard (`manifestVersion: 1`) and the layout format may still be adjusted from feedback before the final release, and will stay compatible after it.
- Player page layouts only apply to the "Classic" audio style; the Flow style and the video player page are unchanged.
- The interface was translated by the developer; some wording may not be idiomatic, and feedback is welcome.
- The names and descriptions of the example plugins, and the NetEase Cloud Music sign-in web page, are still in Chinese; with Traditional Chinese, weather place names are in Simplified Chinese.
- Plugin text replacement only applies to LightPlayer's own interface (including the menu bar / notification area menu and the open, save and confirmation dialogs); the system's own text and notifications aren't replaced.
- Plugins can only use resources in their own folder, not images or fonts from the web.
- The macOS version is not notarized by Apple and the Windows version is not code-signed; the first time you open them, allow them as described above.
- macOS only has an Apple Silicon version for now, no Intel version; Windows only has an x64 version (Windows on ARM can run it through the built-in emulation).
- AI recognition on Windows runs on the CPU without GPU acceleration, slower than on a Mac; a smaller model is recommended.
- The weather theme on Windows can only locate you approximately from the network (the system location service isn't used); if the location is off, choose a city in Settings.
- Windows doesn't let apps make themselves the default player: click "Open System Settings" under "Settings > Library > File associations" and choose LightPlayer in Windows' "Default apps".
- Playing some videos (e.g. HEVC) on Windows may need live conversion, using more CPU than on a Mac.
- When a file is opened by double-clicking it in Finder, macOS itself may add it to "Recent Items"; this is outside private browsing's control.
- AI recognition needs a model download the first time (the recommended model is about 550 MB); a mirror for mainland China can be chosen in Settings.
- The bundled ffmpeg is a GPL build, for personal use only.
- Picture subtitles such as PGS and VobSub are not supported yet.
