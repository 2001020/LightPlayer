# LightPlayer 1.6.0 Beta 4

简体中文 | [English](v1.6.0b4.en.md)

这是 1.6.0 的第四个**预发布版本**，新增**界面语言**：除了简体中文，现在还可以使用繁體中文、English、日本語和한국어界面。仓库中的文档也都有了英文版。Beta 1 到 Beta 3 的全部功能都包含在内。

## 下载与安装

### macOS

- 适用于 **Apple Silicon（M 系列芯片）** 的 Mac，需要 **macOS 12** 或更高版本。
- 下载下方的 `LightPlayer_1.6.0b4_aarch64.dmg`，打开后把 LightPlayer 拖进“应用程序”（可直接覆盖旧版本，媒体库和设置会保留）。
- 本版本未经 Apple 公证。首次打开如果提示“已损坏”或“无法验证开发者”，请在“应用程序”中右键 LightPlayer 选择“打开”，或在终端执行：

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- 适用于 **Windows 10 / 11（64 位）**。
- **安装版（推荐）**：下载 `LightPlayer_1.6.0b4_x64-setup.exe` 并运行，装在当前用户下，不需要管理员权限，开始菜单里会有 LightPlayer，可以在“设置 > 应用”中卸载。
- **便携版**：下载 `LightPlayer_1.6.0b4_x64_portable.zip`，解压后运行文件夹里的 `LightPlayer.exe`（请保留同目录的 `ffmpeg.exe` 和 `ffprobe.exe`）。
- 安装程序未经代码签名。如果出现“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。
- 需要 Microsoft Edge WebView2 运行时：Windows 11 和较新的 Windows 10 已自带；没有的话，安装版会自动下载安装，便携版请先从微软官网安装。

## 新功能

- **界面语言**（设置 > 外观 > 语言）
  - 可选简体中文、繁體中文、English、日本語、한국어，以及“跟随系统”。切换后立即生效，不需要重启，播放也不会中断。
  - 新安装时默认跟随系统语言（系统语言不在上面几种之内时使用英文）；从旧版本升级的用户保持简体中文，可以随时在设置中切换。
  - 整个界面都会翻译，包括按钮提示、右键菜单、对话框、错误提示和桌面歌词窗口；菜单栏 / 通知区域图标的菜单，以及打开、保存、确认对话框的标题和按钮也会跟随所选语言。
  - 日期、时间和数字按所选语言的习惯显示，例如评论时间、识别任务时间、播放页时钟中的日期，以及“1.2万 / 12K”这样的计数。
  - 选择英文、日文或韩文时，天气的地名和城市搜索结果也使用对应语言。
  - 从这个版本起，更新窗口中的更新说明会按界面语言显示中文或英文。
  - 歌词、歌名、歌手、专辑、文件名、歌单名和评论等内容不会翻译。
- **英文文档**：README、开发计划、插件开发标准和所有版本的发布说明都有了英文版（`*.en.md`），每篇开头可以切换语言。之后的发布说明同时包含中文和英文。
- **插件开发标准**
  - 新增页面状态属性 `lang`（`zh-Hans` / `zh-Hant` / `en` / `ja` / `ko`），可以写只在某种语言下生效的样式，例如 `:root[lang="en"]`。
  - 插件文字替换表的原文仍然是简体中文界面文字，与用户选择的语言无关；插件的条目优先于内置语言。
  - 插件的文字替换现在也作用于菜单栏 / 通知区域图标的菜单，以及打开、保存、确认对话框的标题和按钮。
  - 占位符代表的文字也会再查一次表，例如“保存失败：{a}”中的错误信息也能被替换。

## 1.6.0 Beta 3 的内容

- **拖动旋转**：编辑布局时拖动选中元素上方的圆点即可旋转，接近 0°、45°、90° 时自动吸附，按住 ⇧ / Shift 以 15° 为步长，双击圆点归零。
- **没有播放歌曲时也能编辑布局**：在“设置 > 外观 > 播放页布局”中点“编辑…”，会用一首示例歌曲显示播放页。

## 1.6.0 Beta 2 的内容


- **自定义播放页**（播放页右上角的 **布局** 按钮，或 设置 > 外观 > 播放页布局）
  - **封面形状**：方形（可调圆角，调到最大就是圆形）或**黑胶唱片**。唱片播放时转动、暂停时停在当前角度；唱臂在播放时落到唱片上，暂停时抬起移开；带有唱片纹路和光泽。转速、封面在唱片中的大小、唱臂、纹路、阴影都可以单独开关或调整。
  - **内置三种布局**：
    - **默认**：和以前完全一样。
    - **黑胶唱片机**：居中的大唱片，歌名、歌手和歌词在下方。
    - **唱片 + 左右分栏**：唱片在左，歌名、歌手、专辑和两行歌词在右。
  - **可视化编辑**：选“编辑布局…”进入编辑模式：
    - 直接拖动元素改变位置，拖右下角的小方块改变大小；会自动吸附到中线和其他元素的对齐线（按住 ⌥ / Alt 拖动不吸附）。
    - 右侧面板可以精确设置位置、宽度、旋转、不透明度；文字的字号、粗细、字体、颜色、对齐、字间距、斜体、阴影；封面的形状和唱片效果。
    - 每个元素可以设置**切歌时的入场动画**：淡入、上滑、下滑、左滑、右滑、缩放、模糊渐显，可调时长和延迟，点“预览动画”立即看效果。
    - 可以**添加新元素**：文字（可插入歌名、歌手、专辑、播放时间、当前时间等）、图片、时钟、进度条或进度环、播放时间。歌名、歌手、专辑、标签、歌词预览可以隐藏，也可以随时再显示。
    - 元素列表中可以调整上下层顺序；支持撤销 / 重做（⌘Z / ⇧⌘Z，Windows：Ctrl+Z / Ctrl+Shift+Z），方向键微调位置，⌘D 复制，Delete 删除。
    - 设置面板可以移到另一侧，或者先隐藏，好看清整个画面。
    - 点“完成”保存。编辑内置布局时会另存为你自己的布局，原来的布局不变；“取消”放弃修改。
  - 布局按比例缩放，在任何窗口大小、全屏下都保持相同的样子。
  - 可以有多个自己的布局，在“布局”菜单中随时切换、复制、重命名、删除。
  - **导出为插件**：把自己的布局（连同用到的图片）导出成 `.lpplugin`，发给别人后，对方在“设置 > 插件”中安装即可使用。
- **插件可以提供播放页布局**：插件开发标准新增 `layouts`，插件可以附带完整的播放页布局，启用后出现在“布局”菜单的“来自插件”中。标准中说明了布局文件的格式（附 JSON Schema），并新增了布局相关的区域锚点（`player-layout`、`layout-item`、`vinyl`、`tonearm` 等）和页面状态属性 `data-player-layout`。
- **新示例插件** `example.retro-turntable.lpplugin`（**复古唱机**）：唱片在左、外圈是播放进度环，右侧是歌曲信息、歌词和播放时间，角落有时钟和贴纸，并用 CSS 微调布局中的元素。连同原来的三个示例，附件中共有四个示例插件。

## 1.6.0 Beta 1 的内容

- **插件**：改变界面布局、样式、文字和字体，以及播放页和歌词页的样式与设置；插件不能运行代码。附[插件开发标准](https://github.com/2001020/LightPlayer/blob/HEAD/docs/plugins/README.md)。
- **自动更新**：从 GitHub 检查新版本，一键下载、校验并安装。

## 已知限制

- 已安装 1.6.0 Beta 1、Beta 2 或 Beta 3 的用户可以在 App 内直接更新到本版本（设置 > 关于 > 检查更新；预发布版本默认会收到之后的预发布更新）；从 1.5.0 及更早版本升级仍需要手动下载安装。
- 自动更新需要能访问 GitHub（api.github.com 和 github.com）。
- 这是预发布版本，插件标准（`manifestVersion: 1`）和布局格式在正式版前仍可能根据反馈微调；正式版发布后会保持兼容。
- 播放页布局只作用于音频的“经典”样式；Flow 样式和视频播放页不变。
- 界面翻译由开发者完成，个别用语可能不够地道，欢迎反馈。
- 示例插件的名称和说明、网易云音乐登录网页仍为中文；繁體中文界面下，天气地名使用简体中文。
- 插件的文字替换只作用于 LightPlayer 自己的界面（包括菜单栏 / 通知区域菜单和打开、保存、确认对话框），系统自身的文字和通知不会被替换。
- 插件只能使用自己文件夹中的资源，不能引用网络上的图片或字体。
- macOS 版未经 Apple 公证，Windows 版未经代码签名，首次打开需要按上面的方法放行。
- macOS 暂时只提供 Apple Silicon 版本，没有 Intel 版本；Windows 只提供 x64 版本（ARM 版 Windows 可以通过系统自带的转译运行）。
- Windows 版的 AI 识别使用 CPU，没有 GPU 加速，比 Mac 慢，建议用较小的模型。
- Windows 版的天气主题只能按网络大致确定位置（不使用系统定位）；位置不准时请在设置中指定城市。
- Windows 不允许程序自己设为默认播放器：请在“设置 > 媒体库 > 文件关联”中点“打开系统设置”，在 Windows 的“默认应用”里选择 LightPlayer。
- Windows 版播放部分视频（例如 HEVC）时可能需要实时转换，CPU 占用比 Mac 版高。
- 从访达双击打开文件时，macOS 自己可能会把它加入“最近使用的项目”，这不受无痕浏览模式控制。
- AI 识别第一次使用需要下载模型（推荐模型约 550 MB），可以在设置中切换到国内镜像。
- 内置的 ffmpeg 是 GPL 构建，仅供个人使用。
- 暂不支持 PGS、VobSub 等图形字幕。
