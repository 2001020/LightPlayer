# LightPlayer 1.6.1

[简体中文](v1.6.1.md) | English

A fix-up update to 1.6.0: covers no longer cut through each other while swiping in the Flow style, and vinyl records no longer show the tonearm. The macOS and Windows versions are updated together.

## Download and install

### macOS

- For Macs with **Apple Silicon (M-series chips)**, running **macOS 12** or later.
- Download `LightPlayer_1.6.1_aarch64.dmg` below, open it and drag LightPlayer into Applications (it can replace the old version; your library and settings are kept).
- This version is not notarized by Apple. If macOS says it is "damaged" or the developer "can't be verified" the first time you open it, right-click LightPlayer in Applications and choose "Open", or run in Terminal:

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- For **Windows 10 / 11 (64-bit)**.
- **Installer (recommended)**: download `LightPlayer_1.6.1_x64-setup.exe` and run it. It installs for the current user without administrator rights, adds LightPlayer to the Start menu, and can be uninstalled under "Settings > Apps".
- **Portable**: download `LightPlayer_1.6.1_x64_portable.zip`, unzip it and run `LightPlayer.exe` in the folder (keep `ffmpeg.exe` and `ffprobe.exe` next to it).
- The installer is not code-signed. If you see "Windows protected your PC", click "More info", then "Run anyway".
- The Microsoft Edge WebView2 runtime is needed: Windows 11 and recent Windows 10 include it; otherwise the installer downloads and installs it, and for the portable version please install it from Microsoft's website first.

## Fixes

- **Covers cutting through each other in the Flow style**: while swiping or changing songs, the two covers turning at once passed through each other in the middle. Each cover is now drawn on its own and stacked front to back, and the two move slightly apart while turning, so they no longer cut through each other. At rest the covers look the same as before.

## Other changes

- **No tonearm on vinyl records**: the built-in "Turntable" and "Vinyl + two columns" layouts, newly added record covers and custom layouts saved earlier no longer show the white tonearm. To have it back, select the cover while editing a layout and turn on "Tonearm" in the panel on the right.
  - The example plugin "Retro turntable" is updated to 1.0.1 and no longer shows the tonearm either.
  - Plugin development standard: a cover's `arm` in a layout file now defaults to `false`.

## Upgrading

- Users of 1.6.0 or a beta can update in the app (Settings > About > Check for updates).
- Upgrading from 1.5.0 or earlier needs a manual download.

## Known limitations

- Known limitations are the same as in [1.6.0](https://github.com/2001020/LightPlayer/releases/tag/v1.6.0).
