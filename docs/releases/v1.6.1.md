# LightPlayer 1.6.1

简体中文 | [English](v1.6.1.en.md)

1.6.0 的修复更新：修复 Flow 样式滑动时封面互相穿插的问题，黑胶唱片不再显示唱臂。macOS 和 Windows 版本同时更新。

## 下载与安装

### macOS

- 适用于 **Apple Silicon（M 系列芯片）** 的 Mac，需要 **macOS 12** 或更高版本。
- 下载下方的 `LightPlayer_1.6.1_aarch64.dmg`，打开后把 LightPlayer 拖进“应用程序”（可直接覆盖旧版本，媒体库和设置会保留）。
- 本版本未经 Apple 公证。首次打开如果提示“已损坏”或“无法验证开发者”，请在“应用程序”中右键 LightPlayer 选择“打开”，或在终端执行：

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- 适用于 **Windows 10 / 11（64 位）**。
- **安装版（推荐）**：下载 `LightPlayer_1.6.1_x64-setup.exe` 并运行，装在当前用户下，不需要管理员权限，开始菜单里会有 LightPlayer，可以在“设置 > 应用”中卸载。
- **便携版**：下载 `LightPlayer_1.6.1_x64_portable.zip`，解压后运行文件夹里的 `LightPlayer.exe`（请保留同目录的 `ffmpeg.exe` 和 `ffprobe.exe`）。
- 安装程序未经代码签名。如果出现“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。
- 需要 Microsoft Edge WebView2 运行时：Windows 11 和较新的 Windows 10 已自带；没有的话，安装版会自动下载安装，便携版请先从微软官网安装。

## 修复

- **Flow 样式滑动时封面穿插**：左右滑动或切歌时，正在转向的两张封面会在中间互相穿过，看起来像“穿模”。现在每张封面单独绘制、按前后顺序叠放，转动途中也会稍微错开，不会再互相穿过。静止时的样子和以前相同。

## 其他变化

- **黑胶唱片不再显示唱臂**：内置的“黑胶唱片机”“唱片 + 左右分栏”布局、新添加的唱片封面和之前保存的自定义布局都不再显示白色唱臂。如果想要唱臂，可以在编辑布局时选中封面，在右侧面板中打开“唱臂”。
  - 示例插件“复古唱机”同步更新为 1.0.1，也不再显示唱臂。
  - 插件开发标准：布局文件中封面的 `arm` 默认值改为 `false`。

## 升级

- 已安装 1.6.0 或 Beta 版的用户可以在 App 内直接更新（设置 > 关于 > 检查更新）。
- 从 1.5.0 及更早版本升级需要手动下载安装。
