# LightPlayer 1.6.10

[简体中文](v1.6.10.md) | English

Improves the Archive theme: the boxes carry the songs' covers, the lyrics show at the top left, and playback can be controlled right from the bottom left. The macOS and Windows versions are updated together.

## Download and install

### macOS

- For Macs with **Apple Silicon (M-series chips)**, running **macOS 12** or later.
- Download `LightPlayer_1.6.10_aarch64.dmg` below, open it and drag LightPlayer into Applications (it can replace the old version; your library and settings are kept).
- This version is not notarized by Apple. If macOS says it is "damaged" or the developer "can't be verified" the first time you open it, right-click LightPlayer in Applications and choose "Open", or run in Terminal:

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- For **Windows 10 / 11 (64-bit)**.
- **Installer (recommended)**: download `LightPlayer_1.6.10_x64-setup.exe` and run it. It installs for the current user without administrator rights, adds LightPlayer to the Start menu, and can be uninstalled under "Settings > Apps".
- **Portable**: download `LightPlayer_1.6.10_x64_portable.zip`, unzip it and run `LightPlayer.exe` in the folder (keep `ffmpeg.exe`, `ffprobe.exe` and `aria2c.exe` next to it).
- The installer is not code-signed. If you see "Windows protected your PC", click "More info", then "Run anyway".
- The Microsoft Edge WebView2 runtime is needed: Windows 11 and recent Windows 10 include it; otherwise the installer downloads and installs it, and for the portable version please install it from Microsoft's website first.

## Archive theme improvements

- **Covers on the boxes**: each box carries its song's cover on the front; songs without a cover get their title printed instead. The chosen box shows a sharper cover in full color; the other covers sit under a light frosted veil.
- **The chosen box stands out more**: it rises a little higher above its neighbours.
- **Lyrics at the top left**: the current line is bold, and clicking a line jumps there.
- **Playback controls at the bottom left**:
  - The progress bar can be dragged or clicked to jump.
  - Below it: play mode, previous, play/pause, next, NetEase comments (only for NetEase songs), playback speed and volume.
  - The play bar at the bottom no longer shows in this view; keyboard shortcuts work as before.
- **Back to the current song**:
  - A new "Back to the current song" button at the right end of the bottom-left controls moves the array back to the song that is playing.
  - After 5 seconds without input the array also goes back to it on its own.
- **Drag in any direction**: hold the mouse button and the array follows the mouse in any direction, diagonals included; let go and it glides on a little, then stops on the nearest box.
- **Plugins**: new anchors `archive-lyrics` and `archive-controls`. The Archive view has no `transport`, so styles written for it have no effect there.

## Upgrading

- Users of 1.6.0 or later (betas included) can update in the app (Settings > About > Check for updates). 1.6.2 and later download this update over several connections with aria2.
- Upgrading from 1.5.0 or earlier needs a manual download.

## Known limitations

- For the Archive theme, see the known limitations in [1.6.9](https://github.com/2001020/LightPlayer/releases/tag/v1.6.9).
- Covers are taken from the audio files the first time they show, so with many songs they appear one by one.
- LAN sync, A-B loop, the sleep timer and desktop lyrics have no buttons in the Archive view: switch to the lyrics page or the library and use the play bar there (A-B loop also works with the A key).
- Other known limitations are the same as in [1.6.0](https://github.com/2001020/LightPlayer/releases/tag/v1.6.0).
