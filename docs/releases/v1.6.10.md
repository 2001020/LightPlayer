# LightPlayer 1.6.10

简体中文 | [English](v1.6.10.en.md)

改进档案主题：档案盒印上歌曲封面，左上角显示歌词，左下角可以直接控制播放。macOS 和 Windows 版本同时更新。

## 下载与安装

### macOS

- 适用于 **Apple Silicon（M 系列芯片）** 的 Mac，需要 **macOS 12** 或更高版本。
- 下载下方的 `LightPlayer_1.6.10_aarch64.dmg`，打开后把 LightPlayer 拖进“应用程序”（可直接覆盖旧版本，媒体库和设置会保留）。
- 本版本未经 Apple 公证。首次打开如果提示“已损坏”或“无法验证开发者”，请在“应用程序”中右键 LightPlayer 选择“打开”，或在终端执行：

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- 适用于 **Windows 10 / 11（64 位）**。
- **安装版（推荐）**：下载 `LightPlayer_1.6.10_x64-setup.exe` 并运行，装在当前用户下，不需要管理员权限，开始菜单里会有 LightPlayer，可以在“设置 > 应用”中卸载。
- **便携版**：下载 `LightPlayer_1.6.10_x64_portable.zip`，解压后运行文件夹里的 `LightPlayer.exe`（请保留同目录的 `ffmpeg.exe`、`ffprobe.exe` 和 `aria2c.exe`）。
- 安装程序未经代码签名。如果出现“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。
- 需要 Microsoft Edge WebView2 运行时：Windows 11 和较新的 Windows 10 已自带；没有的话，安装版会自动下载安装，便携版请先从微软官网安装。

## 档案主题的改进

- **档案盒印上封面**：每个档案盒正面印着对应歌曲的封面，没有封面的歌曲印上歌名。选中的档案盒显示更清晰的原色封面，其余档案盒的封面蒙着一层淡淡的磨砂。
- **选中的档案盒更突出**：比周围的档案盒升得更高一些。
- **左上角显示歌词**：当前一句加粗，点击某一句可以跳到那里。
- **左下角的播放控制**：
  - 进度条可以拖动或点击来跳转。
  - 下方是播放模式、上一首、播放/暂停、下一首、网易云评论（只在播放网易云歌曲时出现）、播放速度和音量。
  - 这个视图中不再显示底部的播放栏；快捷键照常可用。
- **回到当前歌曲**：
  - 左下角最右边新增“回到当前歌曲”按钮，阵列会移回正在播放的那首。
  - 5 秒不操作，也会自动回到正在播放的歌曲。
- **向任意方向拖动**：按住鼠标拖动时，阵列跟着鼠标朝任意方向移动，包括斜向；松手后会顺势滑一段，再停在最近的档案盒上。
- **插件**：新增锚点 `archive-lyrics` 和 `archive-controls`。档案视图中没有 `transport`，为它写的样式在这里不起作用。

## 升级

- 已安装 1.6.0 及之后版本（包括 Beta 版）的用户可以在 App 内直接更新（设置 > 关于 > 检查更新）。1.6.2 及之后的版本会使用 aria2 多线程下载这次更新。
- 从 1.5.0 及更早版本升级需要手动下载安装。

## 已知限制

- 档案主题的已知限制见 [1.6.9](https://github.com/2001020/LightPlayer/releases/tag/v1.6.9)。
- 封面第一次显示时需要从音频文件中提取，歌曲很多时会逐个出现。
- 局域网同步、A-B 段落循环、睡眠定时和桌面歌词在档案视图中没有按钮：可以切到歌词页或媒体库，在那里的播放栏中操作（A-B 段落循环也可以按 A 键）。
- 其他已知限制与 [1.6.0](https://github.com/2001020/LightPlayer/releases/tag/v1.6.0) 相同。
