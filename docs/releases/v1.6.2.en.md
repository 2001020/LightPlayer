# LightPlayer 1.6.2

[简体中文](v1.6.2.md) | English

Better in-app updates: update packages now download over several connections with the bundled aria2, which is much faster. The macOS and Windows versions are updated together.

## Download and install

### macOS

- For Macs with **Apple Silicon (M-series chips)**, running **macOS 12** or later.
- Download `LightPlayer_1.6.2_aarch64.dmg` below, open it and drag LightPlayer into Applications (it can replace the old version; your library and settings are kept).
- This version is not notarized by Apple. If macOS says it is "damaged" or the developer "can't be verified" the first time you open it, right-click LightPlayer in Applications and choose "Open", or run in Terminal:

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- For **Windows 10 / 11 (64-bit)**.
- **Installer (recommended)**: download `LightPlayer_1.6.2_x64-setup.exe` and run it. It installs for the current user without administrator rights, adds LightPlayer to the Start menu, and can be uninstalled under "Settings > Apps".
- **Portable**: download `LightPlayer_1.6.2_x64_portable.zip`, unzip it and run `LightPlayer.exe` in the folder (keep `ffmpeg.exe`, `ffprobe.exe` and `aria2c.exe` next to it).
- The installer is not code-signed. If you see "Windows protected your PC", click "More info", then "Run anyway".
- The Microsoft Edge WebView2 runtime is needed: Windows 11 and recent Windows 10 include it; otherwise the installer downloads and installs it, and for the portable version please install it from Microsoft's website first.

## Improvements

- **Faster update downloads**: the app now bundles [aria2](https://github.com/aria2/aria2) and downloads an update over up to 16 connections at once, so it uses your full bandwidth even when each connection is throttled.
  - The current speed is shown next to the progress bar; hover over it to see the number of connections.
  - It uses the system proxy (the macOS network proxy settings, the Windows "Proxy server" setting) or the `HTTPS_PROXY` environment variable. Only HTTP proxies work, not SOCKS.
  - The size and SHA-256 are still checked afterwards. If aria2 can't start or the download fails, it falls back to the old single-connection download automatically.

## Upgrading

- Users of 1.6.0, 1.6.1 or a beta can update in the app (Settings > About > Check for updates).
- This update is still downloaded by the old version (one connection); updates after 1.6.2 use aria2.
- Upgrading from 1.5.0 or earlier needs a manual download.

## Known limitations

- Other known limitations are the same as in [1.6.0](https://github.com/2001020/LightPlayer/releases/tag/v1.6.0).
