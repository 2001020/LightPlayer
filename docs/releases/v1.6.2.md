# LightPlayer 1.6.2

简体中文 | [English](v1.6.2.en.md)

改进 App 内更新：内置 aria2 多线程下载更新包，速度更快。macOS 和 Windows 版本同时更新。

## 下载与安装

### macOS

- 适用于 **Apple Silicon（M 系列芯片）** 的 Mac，需要 **macOS 12** 或更高版本。
- 下载下方的 `LightPlayer_1.6.2_aarch64.dmg`，打开后把 LightPlayer 拖进“应用程序”（可直接覆盖旧版本，媒体库和设置会保留）。
- 本版本未经 Apple 公证。首次打开如果提示“已损坏”或“无法验证开发者”，请在“应用程序”中右键 LightPlayer 选择“打开”，或在终端执行：

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- 适用于 **Windows 10 / 11（64 位）**。
- **安装版（推荐）**：下载 `LightPlayer_1.6.2_x64-setup.exe` 并运行，装在当前用户下，不需要管理员权限，开始菜单里会有 LightPlayer，可以在“设置 > 应用”中卸载。
- **便携版**：下载 `LightPlayer_1.6.2_x64_portable.zip`，解压后运行文件夹里的 `LightPlayer.exe`（请保留同目录的 `ffmpeg.exe`、`ffprobe.exe` 和 `aria2c.exe`）。
- 安装程序未经代码签名。如果出现“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。
- 需要 Microsoft Edge WebView2 运行时：Windows 11 和较新的 Windows 10 已自带；没有的话，安装版会自动下载安装，便携版请先从微软官网安装。

## 改进

- **更新下载更快**：App 内置了 [aria2](https://github.com/aria2/aria2)，下载更新包时同时使用最多 16 个连接，单个连接被限速时也能跑满带宽。
  - 下载时在进度条旁边显示实时速度，鼠标移上去可以看到连接数。
  - 会使用系统代理（macOS 的网络代理设置、Windows 的“代理服务器”设置）或 `HTTPS_PROXY` 环境变量；只支持 HTTP 代理，不支持 SOCKS。
  - 下载完成后仍会校验大小和 SHA-256。aria2 无法启动或下载失败时，自动改回原来的单连接下载。

## 升级

- 已安装 1.6.0、1.6.1 或 Beta 版的用户可以在 App 内直接更新（设置 > 关于 > 检查更新）。
- 这次更新仍由旧版本下载（单连接），从 1.6.2 开始，之后的更新才会使用 aria2。
- 从 1.5.0 及更早版本升级需要手动下载安装。
