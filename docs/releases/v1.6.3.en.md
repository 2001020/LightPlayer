# LightPlayer 1.6.3

[简体中文](v1.6.3.md) | English

The weather theme's sky now follows the time of day: nine stages based on local sunrise and sunset, with the colors, the sun, the moon and the accent color changing smoothly over time. The macOS and Windows versions are updated together.

## Download and install

### macOS

- For Macs with **Apple Silicon (M-series chips)**, running **macOS 12** or later.
- Download `LightPlayer_1.6.3_aarch64.dmg` below, open it and drag LightPlayer into Applications (it can replace the old version; your library and settings are kept).
- This version is not notarized by Apple. If macOS says it is "damaged" or the developer "can't be verified" the first time you open it, right-click LightPlayer in Applications and choose "Open", or run in Terminal:

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- For **Windows 10 / 11 (64-bit)**.
- **Installer (recommended)**: download `LightPlayer_1.6.3_x64-setup.exe` and run it. It installs for the current user without administrator rights, adds LightPlayer to the Start menu, and can be uninstalled under "Settings > Apps".
- **Portable**: download `LightPlayer_1.6.3_x64_portable.zip`, unzip it and run `LightPlayer.exe` in the folder (keep `ffmpeg.exe`, `ffprobe.exe` and `aria2c.exe` next to it).
- The installer is not code-signed. If you see "Windows protected your PC", click "More info", then "Run anyway".
- The Microsoft Edge WebView2 runtime is needed: Windows 11 and recent Windows 10 include it; otherwise the installer downloads and installs it, and for the portable version please install it from Microsoft's website first.

## New

- **A sky that follows the time of day**: in the weather theme, the sky goes through nine stages based on local sunrise and sunset: **daybreak, sunrise, morning, noon, afternoon, evening, sunset, night and midnight**.
  - The sky's colors blend continuously between neighboring stages as time passes, with no sudden jumps. Cloudy, rainy and snowy skies also brighten and darken with the time of day, and the horizon glows warm around sunrise and sunset.
  - The sun rises on the left, passes the middle of the sky and sets on the right; at night the moon follows the same arc.
  - The stages follow sunrise and sunset where you are, so they change with the seasons. Before any weather data arrives, a 06:00 sunrise and 18:30 sunset are assumed.
  - The weather popover shows the current stage.
- **Accent color follows the time of day** (Settings > Appearance > Weather, on by default): each stage has its own accent color, such as orange at sunrise, blue at noon, gold in the evening and violet at night, changing smoothly over time. When it's off, the color chosen under "Accent color" is used; with "Color from cover" on, the cover color still wins.
- **Preview** now has the nine stages, so you can see each one at any time. They replace the old "Dusk" and "Clear night" previews.
- Plugins can style each stage with the new `data-time` attribute on `<html>`; see the [plugin development standard](https://github.com/2001020/LightPlayer/blob/main/docs/plugins/README.en.md).

## Upgrading

- Users of 1.6.0 or later (betas included) can update in the app (Settings > About > Check for updates). 1.6.2 downloads this update over several connections with aria2.
- Upgrading from 1.5.0 or earlier needs a manual download.
