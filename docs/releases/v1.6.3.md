# LightPlayer 1.6.3

简体中文 | [English](v1.6.3.en.md)

天气主题新增随时间变化的天空：按当地日出日落分为九个时段，颜色、太阳、月亮和主题色随时间平滑变化。macOS 和 Windows 版本同时更新。

## 下载与安装

### macOS

- 适用于 **Apple Silicon（M 系列芯片）** 的 Mac，需要 **macOS 12** 或更高版本。
- 下载下方的 `LightPlayer_1.6.3_aarch64.dmg`，打开后把 LightPlayer 拖进“应用程序”（可直接覆盖旧版本，媒体库和设置会保留）。
- 本版本未经 Apple 公证。首次打开如果提示“已损坏”或“无法验证开发者”，请在“应用程序”中右键 LightPlayer 选择“打开”，或在终端执行：

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- 适用于 **Windows 10 / 11（64 位）**。
- **安装版（推荐）**：下载 `LightPlayer_1.6.3_x64-setup.exe` 并运行，装在当前用户下，不需要管理员权限，开始菜单里会有 LightPlayer，可以在“设置 > 应用”中卸载。
- **便携版**：下载 `LightPlayer_1.6.3_x64_portable.zip`，解压后运行文件夹里的 `LightPlayer.exe`（请保留同目录的 `ffmpeg.exe`、`ffprobe.exe` 和 `aria2c.exe`）。
- 安装程序未经代码签名。如果出现“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。
- 需要 Microsoft Edge WebView2 运行时：Windows 11 和较新的 Windows 10 已自带；没有的话，安装版会自动下载安装，便携版请先从微软官网安装。

## 新功能

- **天空随时段变化**：天气主题下，天空按当地的日出和日落时间分为九个时段：**破晓、日出、上午、中午、下午、傍晚、日落、夜晚、午夜**。
  - 天空颜色在相邻时段之间按当前时间连续过渡，不会到点突然跳变。阴天、雨雪等天气的天空也会随时段变亮、变暗，日出日落时地平线泛起暖光。
  - 太阳从左侧升起、经过天空正中、在右侧落下；夜里月亮沿同样的弧线移动。
  - 时段按当前位置的日出日落计算，季节不同长短也不同；还没有天气数据时，按 06:00 日出、18:30 日落估算。
  - 天气弹窗中显示当前时段。
- **主题色跟随时段**（设置 > 外观 > 天气，默认开启）：每个时段有自己的主题色，例如日出偏橙、中午偏蓝、傍晚偏金、夜晚偏紫，随时间平滑变化。关闭后使用“主题色”中选择的颜色；开启“随封面变色”时仍以封面颜色为准。
- **效果预览**中新增九个时段，可以随时查看每个时段的样子。原来的“黄昏”和“晴夜”预览由“日落”和“夜晚”代替。
- 插件可以通过 `<html>` 上新的 `data-time` 属性针对时段写样式，详见[插件开发标准](https://github.com/2001020/LightPlayer/blob/main/docs/plugins/README.md)。

## 升级

- 已安装 1.6.0 及之后版本（包括 Beta 版）的用户可以在 App 内直接更新（设置 > 关于 > 检查更新）。1.6.2 会使用 aria2 多线程下载这次更新。
- 从 1.5.0 及更早版本升级需要手动下载安装。
