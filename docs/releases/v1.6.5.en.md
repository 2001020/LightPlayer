# LightPlayer 1.6.5

[简体中文](v1.6.5.md) | English

The layout editor's settings panel can now be dragged. The macOS and Windows versions are updated together.

## Download and install

### macOS

- For Macs with **Apple Silicon (M-series chips)**, running **macOS 12** or later.
- Download `LightPlayer_1.6.5_aarch64.dmg` below, open it and drag LightPlayer into Applications (it can replace the old version; your library and settings are kept).
- This version is not notarized by Apple. If macOS says it is "damaged" or the developer "can't be verified" the first time you open it, right-click LightPlayer in Applications and choose "Open", or run in Terminal:

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- For **Windows 10 / 11 (64-bit)**.
- **Installer (recommended)**: download `LightPlayer_1.6.5_x64-setup.exe` and run it. It installs for the current user without administrator rights, adds LightPlayer to the Start menu, and can be uninstalled under "Settings > Apps".
- **Portable**: download `LightPlayer_1.6.5_x64_portable.zip`, unzip it and run `LightPlayer.exe` in the folder (keep `ffmpeg.exe`, `ffprobe.exe` and `aria2c.exe` next to it).
- The installer is not code-signed. If you see "Windows protected your PC", click "More info", then "Run anyway".
- The Microsoft Edge WebView2 runtime is needed: Windows 11 and recent Windows 10 include it; otherwise the installer downloads and installs it, and for the portable version please install it from Microsoft's website first.

## Improvements

- **Drag the layout editor's settings panel**: hold the bar at the top of the panel to drag it anywhere on the stage, so it no longer covers the elements you're editing.
  - The panel can't be dragged out of the window, and it stays in view when the window gets smaller.
  - Its position is remembered for the next time you edit a layout.
  - Double-click the bar, or click "Put the panel back" in the toolbar, to dock it to the side of the window again.

## Upgrading

- Users of 1.6.0 or later (betas included) can update in the app (Settings > About > Check for updates). 1.6.2 and later download this update over several connections with aria2.
- Upgrading from 1.5.0 or earlier needs a manual download.

## Known limitations

- Other known limitations are the same as in [1.6.0](https://github.com/2001020/LightPlayer/releases/tag/v1.6.0).
