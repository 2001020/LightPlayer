# LightPlayer 1.6.6

[简体中文](v1.6.6.md) | English

Fixes overlapping playback bar buttons in narrow windows and with long song titles. The macOS and Windows versions are updated together.

## Download and install

### macOS

- For Macs with **Apple Silicon (M-series chips)**, running **macOS 12** or later.
- Download `LightPlayer_1.6.6_aarch64.dmg` below, open it and drag LightPlayer into Applications (it can replace the old version; your library and settings are kept).
- This version is not notarized by Apple. If macOS says it is "damaged" or the developer "can't be verified" the first time you open it, right-click LightPlayer in Applications and choose "Open", or run in Terminal:

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- For **Windows 10 / 11 (64-bit)**.
- **Installer (recommended)**: download `LightPlayer_1.6.6_x64-setup.exe` and run it. It installs for the current user without administrator rights, adds LightPlayer to the Start menu, and can be uninstalled under "Settings > Apps".
- **Portable**: download `LightPlayer_1.6.6_x64_portable.zip`, unzip it and run `LightPlayer.exe` in the folder (keep `ffmpeg.exe`, `ffprobe.exe` and `aria2c.exe` next to it).
- The installer is not code-signed. If you see "Windows protected your PC", click "More info", then "Run anyway".
- The Microsoft Edge WebView2 runtime is needed: Windows 11 and recent Windows 10 include it; otherwise the installer downloads and installs it, and for the portable version please install it from Microsoft's website first.

## Improvements

- **Playback bar buttons fold away**: when the window gets narrow, the buttons on the right that don't fit move one by one into a new "More" (…) menu instead of overlapping the play controls.
  - Quality, playback speed, sleep timer and subtitles open submenus there, and show their current setting.
  - When a folded feature is on (speed, timer, desktop lyrics and so on), a dot lights up under the "More" button.
  - The playlist button, and the fullscreen button for videos, always stay on the bar.
  - The A-B loop, hidden in narrow windows, is in the "More" menu too.
- **A smaller volume control**: when space is short, the volume slider becomes a button. Hover over it or click it for a vertical slider, which also has a mute button. The scroll wheel still changes the volume.
- **Long titles scroll**: the song info in the bottom left has a maximum width. Titles and artist names that are too long scroll back and forth instead of pushing the play controls to the right. They don't scroll when the system's "reduce motion" setting is on.

## Upgrading

- Users of 1.6.0 or later (betas included) can update in the app (Settings > About > Check for updates). 1.6.2 and later download this update over several connections with aria2.
- Upgrading from 1.5.0 or earlier needs a manual download.

## Known limitations

- Other known limitations are the same as in [1.6.0](https://github.com/2001020/LightPlayer/releases/tag/v1.6.0).
