# LightPlayer 1.6.6

简体中文 | [English](v1.6.6.en.md)

修复窗口较窄或歌名较长时播放栏按钮重叠的问题。macOS 和 Windows 版本同时更新。

## 下载与安装

### macOS

- 适用于 **Apple Silicon（M 系列芯片）** 的 Mac，需要 **macOS 12** 或更高版本。
- 下载下方的 `LightPlayer_1.6.6_aarch64.dmg`，打开后把 LightPlayer 拖进“应用程序”（可直接覆盖旧版本，媒体库和设置会保留）。
- 本版本未经 Apple 公证。首次打开如果提示“已损坏”或“无法验证开发者”，请在“应用程序”中右键 LightPlayer 选择“打开”，或在终端执行：

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- 适用于 **Windows 10 / 11（64 位）**。
- **安装版（推荐）**：下载 `LightPlayer_1.6.6_x64-setup.exe` 并运行，装在当前用户下，不需要管理员权限，开始菜单里会有 LightPlayer，可以在“设置 > 应用”中卸载。
- **便携版**：下载 `LightPlayer_1.6.6_x64_portable.zip`，解压后运行文件夹里的 `LightPlayer.exe`（请保留同目录的 `ffmpeg.exe`、`ffprobe.exe` 和 `aria2c.exe`）。
- 安装程序未经代码签名。如果出现“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。
- 需要 Microsoft Edge WebView2 运行时：Windows 11 和较新的 Windows 10 已自带；没有的话，安装版会自动下载安装，便携版请先从微软官网安装。

## 改进

- **播放栏右侧按钮自动收纳**：窗口变窄时，放不下的按钮会依次收进新的“更多”（…）菜单，不再和中间的播放按钮重叠。
  - 音质、播放速度、睡眠定时、字幕在菜单里有二级菜单，并显示当前的设置。
  - 收进菜单的功能处于开启状态（如倍速、定时、桌面歌词）时，“更多”按钮下方会亮起小圆点。
  - 播放列表按钮和视频的全屏按钮始终留在播放栏上。
  - 窄窗口下隐藏的 A-B 段落循环也可以在“更多”菜单里找到。
- **音量控件更省地方**：宽度不够时，音量滑条收成一个按钮，鼠标移上去或点击会弹出竖向滑条，里面可以静音；滚轮仍可调节音量。
- **长歌名滚动显示**：左下角的歌曲信息有了最大宽度，歌名或歌手名超出时会来回滚动显示，不再把播放按钮挤到右边。系统开启“减少动态效果”时不滚动。

## 升级

- 已安装 1.6.0 及之后版本（包括 Beta 版）的用户可以在 App 内直接更新（设置 > 关于 > 检查更新）。1.6.2 及之后的版本会使用 aria2 多线程下载这次更新。
- 从 1.5.0 及更早版本升级需要手动下载安装。
