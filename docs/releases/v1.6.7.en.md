# LightPlayer 1.6.7

[简体中文](v1.6.7.md) | English

New: LAN sync playback. Send the file you are playing to another LightPlayer on the same local network, and its playback follows yours in real time. The macOS and Windows versions are updated together, and they can send to each other.

## Download and install

### macOS

- For Macs with **Apple Silicon (M-series chips)**, running **macOS 12** or later.
- Download `LightPlayer_1.6.7_aarch64.dmg` below, open it and drag LightPlayer into Applications (it can replace the old version; your library and settings are kept).
- This version is not notarized by Apple. If macOS says it is "damaged" or the developer "can't be verified" the first time you open it, right-click LightPlayer in Applications and choose "Open", or run in Terminal:

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- For **Windows 10 / 11 (64-bit)**.
- **Installer (recommended)**: download `LightPlayer_1.6.7_x64-setup.exe` and run it. It installs for the current user without administrator rights, adds LightPlayer to the Start menu, and can be uninstalled under "Settings > Apps".
- **Portable**: download `LightPlayer_1.6.7_x64_portable.zip`, unzip it and run `LightPlayer.exe` in the folder (keep `ffmpeg.exe`, `ffprobe.exe` and `aria2c.exe` next to it).
- The installer is not code-signed. If you see "Windows protected your PC", click "More info", then "Run anyway".
- The Microsoft Edge WebView2 runtime is needed: Windows 11 and recent Windows 10 include it; otherwise the installer downloads and installs it, and for the portable version please install it from Microsoft's website first.

## New: LAN sync playback

- **Sending**: open an audio or video file on your computer and click the "LAN Sync" button on the right of the playback bar (in the "More" menu when the window is narrow).
  - The window lists the devices running LightPlayer on the same local network; click "Send".
  - If a device is not listed, enter its IP address or click "Search this network". A device's address is shown in its Settings > LAN Sync.
  - You can send to several devices at once. Files can be up to 1 GB.
- **Receiving**: the other device shows a confirmation window with who is sending, the file name and its size.
  - Nothing is transferred until "Accept" is clicked; the request is declined automatically after 60 seconds.
  - The confirmation window also lets you choose whether to follow the sender's playback.
- **Transfer**: both sides show live progress, speed and time left, and either side can cancel.
  - Received files are saved in the "Movies/LightPlayer" folder ("Videos\LightPlayer" on Windows).
  - A file with the same name gets a new name; nothing is overwritten.
  - A file only appears in the folder once it is complete and its size checked; a cancelled or broken transfer leaves nothing behind.
- **Synced playback**: once the file arrives, the receiver opens it at the sender's current position and follows from then on.
  - Play, pause, jumps and speed changes are all synced.
  - Small differences are evened out by playing very slightly faster or slower, so playback does not keep jumping.
  - A bar at the top of the window shows which device is being followed, with "Stop following".
  - Pausing or jumping on the receiver pauses following; "Resume following" lines it up again.
  - When the sender switches to another file, stops syncing or quits, the receiver is told and syncing ends.
- **Settings**: a new "LAN Sync" page in Settings.
  - "Let devices on the local network find this computer and send media to it": on by default. When off, other devices cannot find this computer, but it can still send to them.
  - Device name: shown on other devices; the computer's name by default.
  - Whether a received file follows the sender's playback.
  - This computer's address and the receive folder, which can be opened from here.

## System prompts the first time

- **macOS** asks whether LightPlayer may find devices on the local network: click "Allow". You can change this later in System Settings > Privacy & Security > Local Network.
- **Windows Firewall** asks whether LightPlayer may access the network: tick "Private networks" and click "Allow".
  - If you click "Cancel", other devices cannot find this computer or send files to it. Turn it back on in Windows Security > Firewall & network protection > Allow an app through firewall.
  - If the current network is set to "Public", tick "Public networks" in the prompt too, or change the network to "Private".
  - The portable version asks again each time it is unzipped to a new place.

## Upgrading

- Users of 1.6.0 or later (betas included) can update in the app (Settings > About > Check for updates). 1.6.2 and later download this update over several connections with aria2.
- Upgrading from 1.5.0 or earlier needs a manual download.
- Both devices need 1.6.7 or later to send to each other.

## Known limitations

- Transfers are not encrypted; use this only on networks you trust (such as your home Wi-Fi).
- With "AP isolation" or a guest network on the router, devices cannot find or reach each other.
- Only files on your computer can be sent, not NetEase Cloud Music songs.
- If the Windows Videos folder is synced by OneDrive, received files are uploaded to OneDrive too.
- With Bluetooth headphones or speakers, each device has its own audio delay, so they may still sound slightly apart.
- Other known limitations are the same as in [1.6.0](https://github.com/2001020/LightPlayer/releases/tag/v1.6.0).
