# LightPlayer 1.6.7

简体中文 | [English](v1.6.7.en.md)

新增局域网同步播放：把正在播放的文件发送给同一局域网中的另一台 LightPlayer，对方的播放进度跟随本机实时同步。macOS 和 Windows 版本同时更新，两个系统之间也可以互传。

## 下载与安装

### macOS

- 适用于 **Apple Silicon（M 系列芯片）** 的 Mac，需要 **macOS 12** 或更高版本。
- 下载下方的 `LightPlayer_1.6.7_aarch64.dmg`，打开后把 LightPlayer 拖进“应用程序”（可直接覆盖旧版本，媒体库和设置会保留）。
- 本版本未经 Apple 公证。首次打开如果提示“已损坏”或“无法验证开发者”，请在“应用程序”中右键 LightPlayer 选择“打开”，或在终端执行：

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- 适用于 **Windows 10 / 11（64 位）**。
- **安装版（推荐）**：下载 `LightPlayer_1.6.7_x64-setup.exe` 并运行，装在当前用户下，不需要管理员权限，开始菜单里会有 LightPlayer，可以在“设置 > 应用”中卸载。
- **便携版**：下载 `LightPlayer_1.6.7_x64_portable.zip`，解压后运行文件夹里的 `LightPlayer.exe`（请保留同目录的 `ffmpeg.exe`、`ffprobe.exe` 和 `aria2c.exe`）。
- 安装程序未经代码签名。如果出现“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。
- 需要 Microsoft Edge WebView2 运行时：Windows 11 和较新的 Windows 10 已自带；没有的话，安装版会自动下载安装，便携版请先从微软官网安装。

## 新功能：局域网同步播放

- **发送**：打开一个本机的音频或视频文件，点播放栏右侧的“局域网同步”按钮（窗口较窄时在“更多”菜单里）。
  - 窗口会列出同一局域网中开着 LightPlayer 的设备，点“发送”即可。
  - 找不到设备时，可以输入对方的 IP 地址，或点“搜索本网段”。对方的地址在它的“设置 > 局域网同步”中可以看到。
  - 可以同时发给多台设备。单个文件最大 1 GB。
- **接收**：对方会看到确认窗口，显示是谁发来的、文件名和大小。
  - 点“接收”才开始传输，60 秒内没有接收就自动拒绝。
  - 确认窗口里可以选择接收后是否跟随发送方的播放进度。
- **传输**：两边都实时显示进度、速度和剩余时间，任何一方都可以取消。
  - 接收的文件保存在“影片/LightPlayer”文件夹中（Windows 为“视频\LightPlayer”）。
  - 重名时会自动改名，不会覆盖原有文件。
  - 文件写完并核对大小后才会出现在文件夹里；中途取消或断开时，不会留下半截文件。
- **同步播放**：接收完成后，接收方自动打开文件，从发送方当前的位置开始播放，之后实时跟随。
  - 播放、暂停、拖动进度、改变倍速都会同步。
  - 细小的偏差会靠轻微调整播放速度慢慢追平，不会频繁跳动。
  - 窗口顶部的提示条显示正在跟随哪台设备，可以“停止跟随”。
  - 在接收方自己暂停或拖动进度会暂停跟随，点“恢复跟随”可以重新对齐。
  - 发送方切换到其他文件、停止同步或退出时，接收方会看到提示，同步结束。
- **设置**：设置中新增“局域网同步”页。
  - “允许局域网中的设备找到本机并发送媒体”：默认开启。关闭后其他设备找不到本机，但本机仍然可以发送给其他设备。
  - 本机名称：显示在其他设备上，默认使用电脑的名称。
  - 接收后是否跟随发送方的播放进度。
  - 显示本机地址和接收文件夹，可以直接打开接收文件夹。

## 第一次使用时的系统提示

- **macOS**：会询问是否允许 LightPlayer 查找本地网络上的设备，请点“允许”。之后可以在“系统设置 > 隐私与安全性 > 本地网络”中更改。
- **Windows**：Windows 防火墙会询问是否允许 LightPlayer 访问网络，请勾选“专用网络”并点“允许”。
  - 如果点了“取消”，其他设备就找不到本机，也不能向本机发送文件。可以在“Windows 安全中心 > 防火墙和网络保护 > 允许应用通过防火墙”中重新打开。
  - 如果当前网络被设为“公用网络”，需要在提示中同时勾选“公用网络”，或把网络改为“专用网络”。
  - 便携版每解压到一个新位置，都会再询问一次。

## 升级

- 已安装 1.6.0 及之后版本（包括 Beta 版）的用户可以在 App 内直接更新（设置 > 关于 > 检查更新）。1.6.2 及之后的版本会使用 aria2 多线程下载这次更新。
- 从 1.5.0 及更早版本升级需要手动下载安装。
- 两台设备都需要 1.6.7 或更新版本才能互相发送。

## 已知限制

- 传输没有加密，请只在信任的网络（例如家里的 Wi-Fi）中使用。
- 路由器开启了“AP 隔离”或“访客网络”时，设备之间无法互相发现和连接。
- 只能发送本机上的文件，网易云音乐的歌曲不能发送。
- Windows 的“视频”文件夹由 OneDrive 同步时，收到的文件也会上传到 OneDrive。
- 使用蓝牙耳机或音箱时，两台设备各自的音频延迟不同，听起来可能仍有细微差异。
- 其他已知限制与 [1.6.0](https://github.com/2001020/LightPlayer/releases/tag/v1.6.0) 相同。
