# LightPlayer 1.6.8

[简体中文](v1.6.8.md) | English

Fixes the progress bar jumping back and forth while an update downloads in the app. The macOS and Windows versions are updated together.

## Download and install

### macOS

- For Macs with **Apple Silicon (M-series chips)**, running **macOS 12** or later.
- Download `LightPlayer_1.6.8_aarch64.dmg` below, open it and drag LightPlayer into Applications (it can replace the old version; your library and settings are kept).
- This version is not notarized by Apple. If macOS says it is "damaged" or the developer "can't be verified" the first time you open it, right-click LightPlayer in Applications and choose "Open", or run in Terminal:

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- For **Windows 10 / 11 (64-bit)**.
- **Installer (recommended)**: download `LightPlayer_1.6.8_x64-setup.exe` and run it. It installs for the current user without administrator rights, adds LightPlayer to the Start menu, and can be uninstalled under "Settings > Apps".
- **Portable**: download `LightPlayer_1.6.8_x64_portable.zip`, unzip it and run `LightPlayer.exe` in the folder (keep `ffmpeg.exe`, `ffprobe.exe` and `aria2c.exe` next to it).
- The installer is not code-signed. If you see "Windows protected your PC", click "More info", then "Run anyway".
- The Microsoft Edge WebView2 runtime is needed: Windows 11 and recent Windows 10 include it; otherwise the installer downloads and installs it, and for the portable version please install it from Microsoft's website first.

## Fixes

- **The update progress bar no longer jumps back and forth**:
  - The bar now has a line of its own with a fixed length. It used to share a line with the downloaded size and the speed, so every change in those numbers made the bar longer or shorter, which looked like it was bouncing.
  - With several connections, a connection that retried could make the downloaded amount dip for a moment. Progress now only moves forward.
  - When the multi-connection download fails and a single connection starts over, a note under the bar says so instead of the bar silently dropping back to 0.
- These fixes apply from the next update on: updating from 1.6.7 or earlier to 1.6.8 still shows the old version's download window.

## Upgrading

- Users of 1.6.0 or later (betas included) can update in the app (Settings > About > Check for updates). 1.6.2 and later download this update over several connections with aria2.
- Upgrading from 1.5.0 or earlier needs a manual download.

## Known limitations

- Other known limitations are the same as in [1.6.0](https://github.com/2001020/LightPlayer/releases/tag/v1.6.0).
