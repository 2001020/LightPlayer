# LightPlayer 1.6.8

简体中文 | [English](v1.6.8.en.md)

修复 App 内下载更新时进度条来回跳动的问题。macOS 和 Windows 版本同时更新。

## 下载与安装

### macOS

- 适用于 **Apple Silicon（M 系列芯片）** 的 Mac，需要 **macOS 12** 或更高版本。
- 下载下方的 `LightPlayer_1.6.8_aarch64.dmg`，打开后把 LightPlayer 拖进“应用程序”（可直接覆盖旧版本，媒体库和设置会保留）。
- 本版本未经 Apple 公证。首次打开如果提示“已损坏”或“无法验证开发者”，请在“应用程序”中右键 LightPlayer 选择“打开”，或在终端执行：

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- 适用于 **Windows 10 / 11（64 位）**。
- **安装版（推荐）**：下载 `LightPlayer_1.6.8_x64-setup.exe` 并运行，装在当前用户下，不需要管理员权限，开始菜单里会有 LightPlayer，可以在“设置 > 应用”中卸载。
- **便携版**：下载 `LightPlayer_1.6.8_x64_portable.zip`，解压后运行文件夹里的 `LightPlayer.exe`（请保留同目录的 `ffmpeg.exe`、`ffprobe.exe` 和 `aria2c.exe`）。
- 安装程序未经代码签名。如果出现“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。
- 需要 Microsoft Edge WebView2 运行时：Windows 11 和较新的 Windows 10 已自带；没有的话，安装版会自动下载安装，便携版请先从微软官网安装。

## 修复

- **下载更新时进度条不再来回跳动**：
  - 进度条单独占一行，长度固定。之前进度条和“已下载大小”、下载速度挤在同一行，这些数字每次变化都会让进度条变长或变短，看起来就像在来回弹。
  - 多线程下载时，个别连接重试会让已下载量短暂变小。现在进度只增不减。
  - 多线程下载失败、改用单线程从头下载时，进度条下方会说明原因，不再无缘无故退回 0。
- 这些修复从下一次更新开始生效：从 1.6.7 或更早版本升级到 1.6.8 时，显示的仍是旧版本的下载窗口。

## 升级

- 已安装 1.6.0 及之后版本（包括 Beta 版）的用户可以在 App 内直接更新（设置 > 关于 > 检查更新）。1.6.2 及之后的版本会使用 aria2 多线程下载这次更新。
- 从 1.5.0 及更早版本升级需要手动下载安装。
