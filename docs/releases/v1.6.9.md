# LightPlayer 1.6.9

简体中文 | [English](v1.6.9.en.md)

新增“档案”主题：当前播放列表排成一片三维档案阵列，点一下档案盒就播放这首歌。macOS 和 Windows 版本同时更新。

## 下载与安装

### macOS

- 适用于 **Apple Silicon（M 系列芯片）** 的 Mac，需要 **macOS 12** 或更高版本。
- 下载下方的 `LightPlayer_1.6.9_aarch64.dmg`，打开后把 LightPlayer 拖进“应用程序”（可直接覆盖旧版本，媒体库和设置会保留）。
- 本版本未经 Apple 公证。首次打开如果提示“已损坏”或“无法验证开发者”，请在“应用程序”中右键 LightPlayer 选择“打开”，或在终端执行：

  ```
  xattr -dr com.apple.quarantine /Applications/LightPlayer.app
  ```

### Windows

- 适用于 **Windows 10 / 11（64 位）**。
- **安装版（推荐）**：下载 `LightPlayer_1.6.9_x64-setup.exe` 并运行，装在当前用户下，不需要管理员权限，开始菜单里会有 LightPlayer，可以在“设置 > 应用”中卸载。
- **便携版**：下载 `LightPlayer_1.6.9_x64_portable.zip`，解压后运行文件夹里的 `LightPlayer.exe`（请保留同目录的 `ffmpeg.exe`、`ffprobe.exe` 和 `aria2c.exe`）。
- 安装程序未经代码签名。如果出现“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。
- 需要 Microsoft Edge WebView2 运行时：Windows 11 和较新的 Windows 10 已自带；没有的话，安装版会自动下载安装，便携版请先从微软官网安装。

## 新功能

- **档案主题**：在“设置 > 外观 > 外观模式”中选择“档案”。
  - 播放页铺满一片斜向排列的白色档案盒，每个档案盒是当前播放列表里的一首歌。列表比较短时会重复排满整个画面。
  - 点一下档案盒就播放这首歌。滚轮在一列中上下换歌；按住 Shift 滚动或横向滚动可以换到别的列；也可以按住鼠标拖动。
  - 鼠标经过的档案盒会浮起，选中时从它周围激起一圈波纹。
  - 中间偏右显示选中歌曲的名称、作者和时长，左下角显示正在播放的名称、作者和进度。界面上没有其他文字。
  - 标题栏和播放栏平时隐藏，鼠标移到窗口顶部或底部时出现。按快捷键时播放栏也会短暂出现。
  - 打开媒体库、歌词页或播放视频时，这些页面照常显示，背后的阵列暂停并虚化。
  - 选中这个主题后，下面有两项设置：“档案浮动”（播放时阵列轻轻起伏）和“画质”（省电 / 标准 / 精细，默认标准）。
  - 这个主题没有任何声音。
  - 效果参考 [LBEILC/RhineLabUI](https://github.com/LBEILC/RhineLabUI)，档案盒模型来自该项目（MIT 许可）。
- **插件**：新增锚点 `archive`、`archive-now`、`archive-selected`；`data-bg` 新增取值 `archive`；`theme` 可以设为 `archive`。详见[插件文档](https://github.com/2001020/LightPlayer/blob/lightplayer-main/docs/plugins/README.md)。

## 升级

- 已安装 1.6.0 及之后版本（包括 Beta 版）的用户可以在 App 内直接更新（设置 > 关于 > 检查更新）。1.6.2 及之后的版本会使用 aria2 多线程下载这次更新。
- 从 1.5.0 及更早版本升级需要手动下载安装。

## 已知限制

- 三维档案阵列需要 WebGL。电脑不支持时，播放页只显示一行提示文字，其他功能不受影响。
- “精细”画质在集成显卡上比较耗电；用电池时建议选“标准”或“省电”。
- 局域网同步播放的已知限制见 [1.6.7](https://github.com/2001020/LightPlayer/releases/tag/v1.6.7)。
- 其他已知限制与 [1.6.0](https://github.com/2001020/LightPlayer/releases/tag/v1.6.0) 相同。
