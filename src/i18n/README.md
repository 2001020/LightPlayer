# 界面语言

简体中文 | [English](README.en.md)

界面用简体中文写成。其他语言是以简体中文原文为键的文字表（`locales/*.json`），由插件也在用的文字替换器（`src/plugins/text.ts`）应用到页面上，插件的文字表叠加在它上面。不经过页面的文字（系统对话框、菜单栏菜单）用 `tr()` 翻译；日期和数字用 `index.ts` 中的格式化函数，按语言习惯显示。

## 添加或修改界面文字

1. 照常在代码中写简体中文。模板字符串和 JSX 中的 `${…}` / `{…}` 部分会变成占位符 `{a}`、`{b}`……
2. 运行 `node scripts/i18n.mjs`，列出各语言缺少的文字。
3. 运行 `node scripts/i18n.mjs --hant` 自动补全繁体中文（OpenCC，台湾用语），并删除源码中已经不存在的条目。之前手动改过的繁体译文会保留。
4. 在 `en.json`、`ja.json`、`ko.json` 中补上译文，占位符要原样保留。

`pnpm test` 会检查每种语言都有全部文字、占位符一致。

- 用户的内容（歌词、歌名、文件名等）放在带 `data-lp-raw` 属性的元素中，不会被翻译。
- 不是界面文字的中文（例如识别模型的提示词、浏览器预览的示例数据）用 `i18n-ignore-start` / `i18n-ignore-end` 注释包起来。
- 界面文字中不要使用“·”。
