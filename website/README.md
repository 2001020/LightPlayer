# LightPlayer 网站

LightPlayer 的产品介绍页，单页静态网站，中文为默认语言，右上角可切换英文（也可以用地址参数 `?lang=en` 或 `?lang=zh` 指定）。

页面里的 App 界面没有使用截图：播放页、歌词页、AI 识别、媒体库、视频页、桌面歌词和菜单栏，都由宣传片的界面绘制代码（`animation-pv/js/ui.js`，按 App 自身的样式和尺寸用 Canvas2D 绘制）实时画出；天气主题的天空、雨雪和播放栏上的水花，视频画面，以及桌面壁纸，由宣传片的 GLSL 着色器（`animation-pv/js/shaders.js`）通过 WebGL2 渲染。

## 观看

直接用浏览器打开 `website/index.html` 即可，也可以在仓库根目录起一个静态服务器：

```bash
npx serve .
# 然后访问 http://localhost:3000/website/
```

网站引用了 `../animation-pv/js/` 下的界面代码、`../assets/icon.svg` 图标，并链接到 `../animation-pv/` 的宣传片，所以发布时要连同整个仓库根目录一起发布（例如 GitHub Pages 选择从仓库根目录发布，网址为 `…/website/`）。

## 交互

| 位置 | 可以做什么 |
|---|---|
| 桌面歌词 | 点色块换桌面歌词的颜色；点菜单栏里的歌名打开菜单栏菜单 |
| 天气主题 | 在雷雨、落雪、星空之间切换（不选时自动轮换） |
| 媒体库 | 在专辑和歌曲视图之间切换 |
| 视频 | 进入或退出沉浸模式；沉浸模式下控制栏会自动隐藏，移动鼠标重新出现 |
| 快捷键 | 在键盘上按对应的键，列表中的按键会亮起 |
| 下载 | 一键拷贝首次打开时需要的终端命令 |

窗口只在进入视野时绘制。系统开启“减弱动态效果”时，页面不做滚动动画，各个窗口显示静止画面。

## 结构

| 文件 | 内容 |
|---|---|
| `index.html` | 页面结构与中文文案 |
| `css/site.css` | 样式 |
| `js/i18n.en.js` | 英文文案 |
| `js/gl.js` | 运行宣传片 GLSL 的小型 WebGL2 渲染器 |
| `js/site.js` | 语言切换、滚动出现效果和各个实时窗口 |

页面中的歌曲、歌手、专辑和歌词都是虚构的示例内容。网站文件不含间隔号（U+00B7），`src/__tests__/no-middle-dot.test.ts` 会一并检查。
