LightPlayer

轻，而无所不能。

一款为 Mac 打造的轻量多媒体播放器。几乎所有格式打开就能播，没有歌词时让它听一遍。

下载 1.1.0 观看宣传片

适用于搭载 Apple 芯片的 Mac，需要 macOS 12 或更高版本。

全格式播放

几乎所有格式，打开就能播。

LightPlayer 内置 FFmpeg。打开文件时，它先分析编码，再结合系统的解码能力，自动选出最合适的播放方式。拖到还没处理到的位置，也会立刻从那里开始。

直接播放

系统原生解码，打开即播，零等待。

  • MP3
  • AAC
  • M4A
  • FLAC
  • WAV
  • MP4

无损转封装

H.264 或 HEVC 视频流原样复制，无损，几乎不占 CPU。

  • MKV
  • FLV
  • TS
  • AVI

音频转换

解码为 FLAC 缓存后播放，音质不打折扣。

  • APE
  • WMA
  • DSF
  • TTA
  • WV

硬件实时转码

用 VideoToolbox 硬件编码为 H.264，边转边播。

  • WMV
  • RMVB
  • MPEG-2
  • 10-bit H.264

歌词

歌词，随歌声流动。

自动加载同名的 LRC、SRT、VTT、TXT 歌词或内嵌歌词，GBK 和 Big5 编码也能认出来。当前一句始终居中，逐字高亮，点按任意一句就跳过去。

翻译与偏移
显示翻译行，整体提前或推后，字号随手调。
歌词编辑器
边听边按空格打点，或逐行微调时间，保存时自动备份。
精确计时
有些下载来的文件会让歌词越走越快，LightPlayer 能自动发现并改用精确计时。

AI 识别歌词

没有歌词？让它听一遍。

点一下“AI 识别歌词”，基于 whisper.cpp 的模型就在你的 Mac 上离线运行，Apple 芯片用 Metal 加速。音频从不离开这台电脑。

  1. 找出人声Silero VAD 跳过前奏和间奏
  2. 增强人声突出人声所在的频段
  3. 本地识别Whisper 模型，Metal 加速
  4. 清理结果过滤幻觉内容，繁体转简体
  5. 逐字对齐生成逐字时间轴，随歌声高亮

首次使用时下载模型，推荐模型约 550 MB，可切换到国内镜像。识别结果会标明由模型生成，可以直接进编辑器校对。视频也能用同样的方式生成字幕。

桌面歌词与菜单栏

桌面歌词，浮于一切之上。

一行歌词悬浮在所有窗口之上，换行时轻轻滑入。按住拖到任何位置，拉伸边角调整大小。关掉主窗口，音乐照常播放，菜单栏图标可以暂停、切歌或重新打开窗口。

换个颜色试试，也可以点菜单栏里的歌名。

天气主题

窗外的天气，也在窗内。

选择“天气”外观，LightPlayer 会按你所在位置的实时天气，把整个界面换成动态的天空。雨滴落在播放栏上溅起水花，雪会积起薄薄一层，再慢慢融化。

晴天的阳光、云、雨、雷电、雪、冰雹、雾和星空都有。天气数据来自 Open-Meteo，地名来自 BigDataCloud，都免费且无需账号。

媒体库

整个音乐库，井然有序。

添加文件夹，子文件夹一并扫描，每次打开时增量刷新。按歌曲、专辑、艺术家和视频浏览，搜索、排序、收藏；自建歌单，或者把一个文件夹直接导入为歌单。

视频

看电影，同样出色。

沉浸式全屏时，控制栏和顶栏自动隐藏。外挂和内嵌字幕都能显示，没有字幕就让 AI 生成。截图、逐帧步进，分辨率、帧率、码率、编码和 HDR 信息一查便知。

还有更多。

  • A-B 段落循环

    反复聆听任意一段，按 A 设定起点和终点。

  • 倍速播放

    0.5× 到 3×，音调保持不变。

  • 睡眠定时

    到时渐弱暂停，或者等这首歌放完。

  • 断点续播

    再次打开，从上次停下的地方继续。

  • 无痕浏览

    不进最近播放，不记播放位置，不加进媒体库。

  • 歌词编辑器

    打标、逐行编辑、预览，保存到歌曲旁边。

  • 播放模式

    顺序、列表循环、单曲循环和随机，随机一轮内不重复。

  • 应用内音量

    只调 LightPlayer，系统音量保持不变。

  • 外观随心

    浅色、深色或跟随系统，主题色可以随封面变化。

  • 设为默认播放器

    一键关联常见音视频格式，双击文件就开始播放。

  • 媒体键与控制中心

    键盘上的媒体键和控制中心都能控制播放。

  • 识别任务队列

    整个歌单一次加入，排队识别，可暂停和调整顺序。

快捷键

双手不离键盘。

几乎每个操作都有快捷键。在这里按一下键盘试试。

  • 空格播放或暂停
  • ←→快退、快进
  • JL后退、前进 15 秒
  • ↑↓音量
  • M静音
  • ⌘←⌘→上一首、下一首
  • ⌘O打开文件
  • ⌘L媒体库
  • ⌘,设置
  • Y歌词页
  • E歌词编辑器
  • I视频信息
  • F全屏
  • S截图
  • ,.逐帧
  • []调速
  • AA-B 循环
  • ⇧⌘N无痕浏览
  • ⌘+⌘−歌词字号
  • Esc返回

下载 LightPlayer

免费下载，源代码公开在 GitHub。适用于搭载 Apple 芯片的 Mac，需要 macOS 12 或更高版本。

下载 1.1.0 在 GitHub 上查看源代码

  1. 下载安装包

    在 GitHub Releases 下载最新的 LightPlayer_1.1.0_aarch64.dmg。

  2. 拖进“应用程序”

    打开 .dmg，把 LightPlayer 拖进“应用程序”文件夹。升级时直接覆盖，媒体库和设置都会保留。

  3. 首次打开

    安装包未经 Apple 公证。如果提示“已损坏”或“无法验证开发者”，在“应用程序”里右键 LightPlayer 选“打开”，或者在终端执行：

    xattr -dr com.apple.quarantine /Applications/LightPlayer.app

暂时只提供 Apple 芯片版本。AI 识别第一次使用时需要下载模型。

GitHub 版本说明 宣传片

应用代码可自由使用。随包分发的 FFmpeg 为 GPL 构建，仅以独立进程方式调用；Whisper 模型与 whisper.cpp 为 MIT 许可。

LightPlayer 使用 Claude 构建。页面中的界面由代码实时绘制，歌曲、歌手和歌词均为虚构示例。
